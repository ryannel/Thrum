# Next goal after V1: a swarm-survival test game

The owner set this on 10 November 2026. Once V1 lands, the next goal is an original game in the swarm-survival
genre that Vampire Survivors made popular, built on Thrum to test the engine. Thrum is a reusable engine, so the
game exists to prove engine capabilities in a real product. It doesn't belong inside the engine.

## What the owner asked for
- **A swarm survivor.** One or more players hold out against ever-growing crowds of enemies, with automatic
  attacks and upgrades between waves. It's an original game: its own name, characters, art and rules.
- **2D support in the engine.** The engine supports 2D games as well as 3D, and this game proves it.
- **Multiplayer.** Several players play together over the network.

## Defaults until the owner says otherwise
These fill gaps the owner didn't specify. The planner may change any of them with reasons, and lists the changes for
the owner.
- Cooperative online play for 2 to 4 players. This uses the transport work the build plan already reopens after V1.
- Top-down 2D with sprites, on V1's targets: Mac, Chrome and the iOS simulator.
- Thousands of enemies and projectiles on screen at once, because large crowds are this genre's load and stress the
  simulation, rendering and network replication together.

## How it is planned
After V1's module plan lands, a planner extends the project plan with 2D, multiplayer and the game as modules and
milestones, in an order that builds up to the game. It reuses V1's contracts, and changes them only with the producing
and consuming modules.
