## Decision and causal gap

Keep material history at **fixed source locations**, and integrate local events in time order. Do not distribute existing liquid over the current whole-cell dry/wet subsets after a shoreline change. Source-area clipping and extra time slices cannot recover location information already discarded by that homogenization.

The proposed `fixed-material-columns-v1` uses at most **8192 independently stored columns total**, not 8192 parent cells each hiding unbounded children. Each column is attached to one immutable microfragment of the actual source patch and one fixed representative point, with positive projected/true-area weights. Its surface liquid and absorbed liquid never move to another column except through an explicitly authored transfer. Wet versus dry is a mode selecting the interpretation and rates of that same surface liquid; a moving water interface does not cause spatial mass remapping. Derived exposed film is `M_d=L` when dry, zero when wet; bound coating is `M_w=L` when wet, zero when dry. Absorbed `A` remains local. A parent response patch may aggregate these values for reporting, never feed the aggregate back as state.

This eliminates whole-cell homogenization **in this discrete physical representation**. A representative column is not an exact area-integrated continuum. Its spatial approximation and its source-first-hit approximation require the separate certificates below. In particular, the existing exact continuous-area rain receipt must not be poured into these point histories at the end of a tick. That would restore the chronology defect. Adoption therefore needs a jointly admitted source/material profile; the existing analytic first-hit path remains its independent continuous-area reference. If that contract change is rejected, this candidate is a useful challenger, not a drop-in completion of C09.

| Alternative | Consequence | Decision |
| --- | --- | --- |
| Whole-cell dry/wet stores with endpoint remap | Conserves total while changing unrelated locations and timed receipts | Reject for required chronology |
| More clip leaves sharing those stores | Better geometry, same information loss | Reject as a material fix |
| Runtime spatial cohorts/polygon density fields | Can retain richer histories, but topology and polynomial/nonlinear state grow with repeated events; needs merge/error rules | Richer later provider |
| Fixed source columns with ordered local events | Fixed memory, independent histories, simple nonnegative balances; spatial error must be admitted | Selected challenger for this commission |
| Full film/seepage PDE or MPM | New constitutive, transport and solver obligations absent from this game law | Not required to close this gap |

## Source products and exact ownership

F3 authors the physical material resolution, material law, permitted wave/tide/finite-water models, requested local errors and required receiver closure. F4 overlays source triangles, roof/top/underside identities, rain cells, material boundaries, water-domain/base-cell boundaries and W2 ownership boundaries **before** creating columns. No column crosses one of these boundaries. Its reference point and disjoint footprint live in exact/certified source coordinates. Roofs and bridge undersides retain separate PatchIds. Vertical faces carry zero direct vertical-rain projected weight but can retain material state under a separately selected exchange law.

Each proposed immutable column record contains `(PatchId, fixed ColumnId, geometry/product revision, barycentric point, projected geometric area A_h, true area A_s, static direct-first-hit projected weight A_r, source rain-cell index, water domain/base-cell index or none, material index)`. IDs derive from authored/cooked source identity, not runtime clipping order. True/projected weights are distinct; `A_s/A_h` is the actual source-triangle area ratio. F4 uses fixed triangular microfragments and splits static top-solid/shelter edges before columns: in this restricted profile `A_r` is exactly `A_h` for a top eligible solid and zero for a sheltered lower solid. A floor under a roof/bridge can have positive A_h/A_s but A_r=0. Its water contact/refill uses A_s and the material wet-support function; it creates no second rain-to-solid or direct-water-rain receipt. Only the eligible top receiver's column can route its footprint's rain to water when overtopped. Unsupported dynamic shelter/solid ordering invalidates the product.

Disjoint **eligible rain** footprints plus explicit exports cover each admitted source rain cell once; overlapping projected roof/floor material footprints do not each receive that area weight. Source rain exposure and material water contact are distinct classifications: a submerged floor under an exposed roof can be materially wet while the roof remains first rain receiver. Atom and column geometry reference the same F4 source binding as P3/V2/water optics. F4 may choose anisotropic microfragments using the admitted directional wave/material error envelope; it cannot silently change them when a graphics tier changes.

Mutable state may expose the existing three local mass fields `M_d,M_w,M_a` in kg, with `L=M_d+M_w` and one of the first two exactly zero at the representative point. Local transitions rename that same surface inventory; they never average it with another column. Retain three conservative error radii and receipt cursors at their owning stream. Wet status is derived from the exact selected water source at the requested time; saved mode caches are validated against that source. One column has at most one possible water donor in this profile. Overlapping physical water owners, moving solid geometry or an unsupported phase require another product/profile. Initial wet columns require `L<=r_w A_s`; excess initial inventory must have an explicit initialization transfer.

W2 pins the union of physical column, source, water, material and drain recipients before stepping. P7 saves the local masses, error envelope, source/build/model binding, pending inventory and complete receipt/control cursors. Recreating display textures cannot change these. A cook/resolution edit requires restart or a reviewed conservative local remap, never an automatic interpolation of a parent wetness scalar.

## First complete chronological law

The first proof deliberately selects a smaller constitutive law than the full terrain proposal: constant nonnegative dry rain, nonnegative finite-rate wet refill, instantaneous wet-entry coating cap, and retention on ebb. Absorption, evaporation, drainage, snow and thermal phase change are disabled by an explicit test-material binding; `A` is retained unchanged. Their future activation needs a specified local flow map and its timing/error proof. They are not represented by pretending their rate is implicitly zero in a required consumer. This restriction isolates the newly failing mechanism while retaining rain, dry/wet reversals, source-limited coating and a named water exchange.

For each maximal interval with fixed mode and constant rates:

* Dry: `L' = L + A_r integral(P dt)`; rain-to-solid is that same mass. Sheltered A_r=0 makes this zero even with positive true area. Deposits with a particular time are inserted at that time, not spread across the tick.
* Wet: direct rain `A_r integral(P dt)` is delivered to the first-hit water owner, not `L`; a sheltered lower column with A_r=0 contributes none. Refill adds `min(r_w A_s-L, k_w A_s dt, grant_remaining)` to `L`, with an equal donor/reservoir debit. No deficit means zero refill.
* Dry→wet: retain `min(L,r_w A_s)` and transfer the excess to the named water inventory. A resolved named material deposit while wet invokes the same cap immediately after its arrival. Wet→dry retains exactly `L`; it does not restore a target film.

`L_new + released = L_old + solid_rain + refilled + resolved_deposition` holds per column. Every resolved deposition has an equal named donor debit or external-reservoir receipt, separate from rain/refill. Direct-water rain and source export are distinct receipts, so complete external rain equals solid-rain plus direct-water-rain plus explicit rain-export. Cap release and refill cancel against water/pending/external ledgers once. No material column spreads another column's absorbed mass or film. Linear-rate source knots split the integration algebra; the provided experiment uses constant rates, so linear-rate constitutive extensions remain unrun.

The candidate processes source/deposition events, local water crossings and cap hits in timestamp order. At a simultaneous knot, apply the prior open interval's flow, named deposition at the knot under the declared contact mode, then the right-hand wet/dry transition and cap, then begin the new open interval. Equality is dry for a point query, but distinguish two tangencies: dry-side grazing (`f<=0` around an isolated f=0) has no positive-duration wet interval; wet-side grazing (`f>=0` around an isolated f=0) has no positive-duration dry interval. Their surrounding modes cannot be interchanged. For an instantaneous deposit exactly at either tangency, use the dry equality mode for its arrival, then the certified right-hand mode and cap; a wet-side graze can therefore process deposited excess before returning to wet refill. The isolated equality alone does not move existing liquid or trigger an additional empty wet/dry cycle. Zero-duration arguments apply to rate integrals, not to finite deposits/caps. The current toy proves only sign-changing roots and supplied discrete transitions; tangent classification and coincident deposition remain unimplemented/unproved. Source-off makes new rain zero while retained columns/refill and existing pending receipts continue according to their separately selected gates.

Local material events are additional **constitutive evaluations**, not independent clocks or water updates. Retain at most 16 global physical water/material barriers per F1 tick. Permit at most two isolated wet/dry transitions per column per barrier in this first profile, plus admitted source knots. Count their evaluations explicitly. This is a proposed refinement of the chronology work bound, requiring owner adoption; it must not be passed off as proof of a one-update full material/water solve. The source/finite-water path determines each barrier before columns consume it.

## Prescribed and finite water are different

A prescribed source supplies the actual point function `f(x,t)=eta(x,t)-bed(x)` and interval/derivative information. Split its point timeline at source knots and analytic extrema, isolate every sign-changing root, and use ordered root brackets. No endpoint-only sampling is allowed. If a leaf cannot certify a mode or the complete crossing count/order within work limits, refine within the admitted cap or refuse. For a fixed single sinusoid over a static mean, shared bed/phase groups can reuse crossing-phase brackets and shift them by `k·x/omega`; a changing mean, extra component or different bed invalidates that shortcut unless independently justified.

Finite water retains the selected solver's **discrete** trajectory: support is frozen within its admitted substep and changes at its staged endpoint. Columns do not invent continuous crossings between two HLL/capacity states. Wet-entry cap excess goes into real identified pending inventory for the same base cell; it is delivered at the next admitted water barrier, subject to the existing 0.5 mm stage/0.01 m shore-effect bounds and one-substep/tick residence limit. Refuse before any publication if those bounds or the recipient closure fail. A pending delivery may change support once; new cap excess is a new pending receipt, not recursive current-stage injection.

For finite refill, compute per-column requests under the frozen contact interval, then share one donor-cell allowance `G<=rho V_start/4` using `g_i=request_i*min(1,G/sum requests)` in deterministic index order, with a certified rounding residual recipient. This prevents first-column priority and borrowing future rain/face inflow. Each local refill consumes its grant only during its admitted wet interval. Water debits the identical summed mass and proportional horizontal momentum once, recording ground reaction. Actual stage/support shift still needs the water owner's bound; the quarter-volume rule alone is not a shore-accuracy proof. The offline experiment does not execute this finite-water coupling.

## Spatial and temporal error/refusal, without an inventory loophole

There are three separate errors: continuous first-hit versus column sampling, within-fragment material history variation, and numerical event/integration arithmetic. Record their local sum and accumulated history envelope, not just global conservation. The comparison vector includes final `L,A`, pending mass and every named outgoing/incoming exchange; exposed/coating labels additionally require admitted endpoint support. A point's mode cannot certify the entire microfragment wet for P3/optics.

1. Source-first-hit requires a **representative-to-footprint mismatch set**, not merely the wave Taylor upper/lower ambiguity band. For eligible footprint F_i, let r_i(x,t) be its actual first receiver, and q_i(t)=r_i(p_i,t) the representative's receiver. Define `M_rain,i={(x,t) in F_i*I : r_i(x,t)!=q_i(t)}` and `U_rain,h=integral_I area_xz(M_rain,i(t)) dt`. Then a per-receiver rain discrepancy is bounded by `P_max U_rain,h`; total receiver-vector L1 error is at most `2 P_max U_rain,h`. A_r=0 has no rain mismatch integral, but can still have material-mode mismatch. Static export footprints keep their own exact mass. Do not normalize inaccurate local weights to conceal this discrepancy.
2. Material chronology uses its own set `M_mat,i={(x,t): wet_material(x,t)!=wet_material(p_i,t)}` over the source patch, with true-area-time `U_mat,s`. This can differ from M_rain under a roof. For the restricted nonbinding-cap law, write surface liquid as **one local store**; mode changes only its finite rate. A safe final-surface-state/refill/rain joint bound is `2(P_max A_r/A_s+k_w) U_mat,s`, plus initial reconstruction/error envelopes, when static eligibility is uniform on the fragment. This remains small for an interior turning-point pulse; it has no starting-inventory term because no spatial redistribution or instantaneous mass release occurs. Verify `L_upper+possible dry rain+possible refill<=r_w A_s` over every potentially wet support before selecting this branch. Carry the prior envelope; do not reset it every tick. **Film versus coating labels need an additional endpoint charge:** define `E_mat,i={x: wet_material(x,t_end)!=wet_material(p_i,t_end)}` and charge `2*(L_upper/A_s)*area_s(E_mat,i)`, using a certified density upper bound, or use a separately proved spatial reconstruction. Taylor geometry ambiguity alone does not bound this endpoint mismatch either. The worked turning-point patch is dry everywhere at both endpoints, so this particular charge is zero there.
3. If all points have the same ordered event word and cap maps, with corresponding event times in brackets of width `delta_j`, align the event sequences. The first profile's additive/capped-refill flow and cap-release map are nonexpansive in the joint mass norm: splitting a scalar between retained/released mass cannot magnify an input difference. Different durations perturb at most `2 A_s R_max sum(delta_j)` mass, with `R_max=P_max A_r/A_s+k_w` and a conservative sum over all segment-duration endpoint differences. Use an extra factor two when converting independent root-time errors into adjacent duration errors. Cap hits and source/deposition ordering must be included in that event word. The current point-wave proof uses the simpler nonbinding branch, not this broader cap certificate.
4. When a cap can fire in a fragment with uncertain event word, bound possibly released excess `E_i=max(0,L_upper+incoming_upper-r_w A_s)` and charge at least `2 E_i` plus the rate/time bound. If it is unclear whether repeated cap/refill sequences fit that estimate, fall back to the prior sound `2B_i` inventory bound **for that independently stored column**, not a larger parent cell. A timed localized deposit unresolved inside a footprint likewise needs its own certified subdivision/profile or refusal; this experiment proves deposition at resolved fixed columns, not arbitrary unresolved splashes.

Use the governing proposed local request `1e-5 kg + 1e-3*processed exchange mass`, allocated across source, spatial chronology and arithmetic, plus the game-selected accumulated state tolerance. Endpoint geometry/topology and shore displacement remain separate requirements. More time slices cannot reduce a spatial uncertainty floor. At 8192 columns/16 barriers/work caps, refuse rather than merge independently different histories, drop a crossing, or claim fewer rendered pixels improve physical accuracy. Ordinary run-up with a nonbinding cap has a shrinking rate/area-time bound; mass-bearing uncertain cap pulses may still require a finer cooked profile or narrower admitted wave envelope.

### Constructing the mismatch enclosure, including exact affine cuts

For either binary classification on one source triangle, let W(t) be the actual wet/first-water region and q(t) the corresponding representative mode. When q=0 the mismatch area is `area(W(t))`; when q=1 it is `area(F_i)-area(W(t))`. These nonnegative quantities must be integrated even when W is known exactly. For affine stage/bed, prepare the exact piecewise-quadratic wet-area law, split at every stage knot, triangle-vertex critical-height crossing, representative-mode crossing and source-rate knot, then integrate the appropriate polynomial or its complement. Linear rain multiplies it into a cubic. Material true-area mismatch multiplies each source triangle's projected integral by its own constant `A_s/A_h`; never use a parent-average ratio over different source triangles. Endpoint mismatch uses the same area/complement choice at t_end. Covered-floor rain eligibility is already zero and does not suppress its separate material wet-area integration.

For waves, obtain certified sets `W_minus(t) subset W(t) subset W_plus(t)` from the spatial/time interval/Taylor producer. On a time leaf with certified q=0, integrate an upper enclosure of `area(W_plus)`; with certified q=1, integrate `area(F_i)-area(W_minus)`. If q is unresolved within its root bracket, charge the **whole footprint** for that bracket, or refine with a certified joint point/footprint bound. Use rate maxima per source segment or certified weighted integrals. This combines actual spatial mode variation with geometric enclosure error. The thin set `W_plus minus W_minus` measures only uncertainty in the wave approximation; it is **not** the representative mismatch set. Protected topology and complete receiver labels still need their own checks. Generic wave mismatch integration is proposed, not implemented by the point-root toy.

Exact affine counterexample: F is the unit square, bed `b=x`, stage `eta=t`, I=[0,1], representative x=1/2. The Taylor/geometry ambiguity band is identically empty. Actual wet area is t; representative mode is dry until 1/2, then wet. The mismatch area-time is `integral_0^.5 t dt + integral_.5^1(1-t)dt = 1/4 m² s`. Independently integrating each point's wrong-mode duration `|x-1/2|` over x gives the same 1/4. With P(t)=t, true direct-water mass is 1/3 kg, representative mass is 3/8 kg, discrepancy 1/24 kg; the exact weighted mismatch bound is 1/8 kg. A zero Taylor-band bound would falsely certify zero sampling error. The toy now retains this one exact analytic counterexample and the independent space-first/time-first check; it still does not implement a general spatial certificate producer.

## Cost before implementation

Proposed packed widths, not Rust size measurements: immutable column geometry/indices including explicit direct-rain weight A_r now cost 104 B*8192 = 0.8125 MiB, plus explicit identity tables/index products. Three local mass stores cost 3*8=24 B/column; three f64 error radii cost another 24 B; mode/status/padding brings the proposed state to 64 B/column = 0.5 MiB/endpoint. Two committed endpoints plus one candidate cost 1.5 MiB; a separate captured save adds 0.5 MiB unless it aliases a leased immutable endpoint. No per-crossing polygon/state allocation belongs in the tick.

The literal conversion cost is `N_old * multiplier * 3 * 8 B` for just the masses, before error/status/owner overlap. At 8192 legacy fragments, multipliers 1/4/16 require 8192/32768/131072 independent columns and 0.1875/0.75/3 MiB of mass scalars per endpoint; four old/current/staged/save owners require 0.75/3/12 MiB of those scalars alone. At the full 64 B state layout the same four-owner totals are 2/8/32 MiB, plus 0.8125/3.25/13 MiB immutable geometry. **Only multiplier 1 fits this proposed 8192-total profile.** Refining a parent into four requires reducing active parent count to <=2048; refining into sixteen requires <=512 parents, or a newly admitted higher cost profile. This is not a promise that every existing 8192-fragment scene can adopt the finer state at unchanged coverage.

At 8192 columns and 16 global barriers, full scanning is 131072 column/barrier visits per tick, 7,864,320/s at 60 Hz. The two-crossing cap allows 262144 local transitions/tick before source knots, but the existing **global 1048576 interval-evaluation cap** applies jointly to classification/root/chronology work, not independently to each subsystem. With 64 refinement evaluations per root, the all-columns/all-barriers worst case would demand 16,777,216 evaluations and must refuse; it is not an admitted performance promise. A 16-component evaluation also multiplies harmonic work. Instrument visits, roots, rate segments, shared phase/template hits, interval leaves, coefficient evaluations and numerical refusals. The Python point test's 63 sign evaluations are neither an optimized runtime cost nor a full-closure measurement.

Retain the E1 maximum 256 source/control knots crossed in a tick, shared across the selected source, and add at most 256 resolved instantaneous material-deposition events across this whole closure per tick. The naive rate-flow upper bound before sparse reuse is `8192*(16+32+256)+256=2490624` constant-law pieces/tick, about 149 million/s at 60 Hz; a smooth low-event workload is far smaller. Set a separate provisional **262144 local flow-piece evaluations/tick** refusal cap, counted jointly across columns and all barriers, so the source-knot worst case is explicitly outside this first profile. Restricting a game to the supported knot/event envelope is a physical-profile admission, not a display-quality reduction.
