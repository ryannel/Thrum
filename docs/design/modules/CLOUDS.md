## Scope and maturity

The [commission](../../evidence/cloud-sky-design-2026-11-01/COMMISSION.md) requires CF01–CF05 (Cu, Cb, Sc, St, Ci),
CW01–CW04 weather transitions, FS01–FS04 complete skies and CL01–CL30 shared obligations. Each genus needs meaningful
variants, recognizable structure, local formation, mature renewal and breakup, coherent height wind, convincing light,
receiver shadows and independent reflected appearance. All remain partial/unproven except the explicitly scoped older
witnesses. Pretty stills, positive arithmetic, tests, a source hash and review agreement cannot promote them.

Scientific meteorology, full conservation, all WMO genera, extra optical phenomena, tornadoes and unrestricted flight
are optional. Rain/lightning **causes and integration seams** are required; their rendered effects remain separate.
The current commission includes standalone construction and proof; Thrum is still a Rust scaffold without an engine runtime.
Standalone proof admission and actual engine/platform admission are separate.

E1/W1 owns committed causes/time; F2 provider/capability declarations; F4 immutable admitted inputs/cook/leases;

final upscaler or exposure transform. No speculative crates or wholesale prototype/engine import.

| Handoff | Meaning and consumer obligation |

Clear, attenuation-only, visible and reflection/environment-only providers declare actual domains. Main-off retains
required source/light/environment facts; all optical consumers removed retires cloud GPU allocations after readers
finish. Headless facts require no GPU/readback. Save/replay/network retain causes and source revisions, not GPU caches.
Provider replacement initially validates/cooks/restarts; seamless live migration is not promised. Unsupported/missing
capacity returns invalid/unavailable, never fabricated clear. Device recovery rebuilds from admitted recoverable inputs.

## One source and one transport authority

Metres/seconds and scene-linear light units are explicit at boundaries. Independent constituents add coefficients;
multiple representations or quality levels of one condensate partition/substitute once. An internal geometry union constructs one final amount before optical sampling; it does not add proxy copies. Near/far levels substitute,
not add. Prepared coefficients use a fixed optical calibration; liquid/ice scattering channels remain meaningful
through interpolation/LOD. They are authored optical proxies, not conserved meteorological water by assertion.

Shared wind acts once in the live3D source update, at material height. E1 supplies spatial/time controls and W; the
source adds named internal updraft/outflow/fall terms without redefining world wind. The source provider must change actual3D support/topology under new forcing; its replacement lifecycle mechanism remains
unqualified after the pulse/transport failure. Main/mirror/light never add a second source
wind. Control/seed/source checkpoints make replay/recovery explicit; optical GPU state is distinct from CPU semantic
weather/causes. All families publish the same representation-neutral query and current source time. P1b validates
Cu/Cb, dense Sc/St and thin Ci before source layout/library freeze. See baseline for exact operators and lifecycle.

V3 integrates summed local extinction/source over overlapping air/fog/cloud intervals with one prefix throughput.
Disjoint affine operators compose front A/rear B as `(S_A+T_A*S_B,T_A*T_B)`. Clear-air LUTs replace only disjoint,
compatible segments; ill-conditioned cumulative differences use a bounded stable segment/reference path. Sun disk,
surface light and medium direct source receive the same air/cloud/geometry attenuation once. Hillaire higher-order
clear-air light is an explicit low-frequency approximation under local shadows, not cloud/fog multiple scattering.

Environment capture and ordinary main/reflected views call the same integration mechanism in ordered modes. Environment
terminals are admitted space/ground/direct-only inputs, avoiding feedback from the environment being built. Clouded
irradiance feeds surfaces, which then supply ordinary-view terminals. Reflected rays begin at the interface and receive
the eye-to-interface operator once. A perfect planar mirror proves this boundary, not production rough-water reflection.

A candidate FrameOptics graph publishes only compatible source/air/Sun/fog/geometry/lighting/view dependencies. Regional
immutable content can be reused only while conservative read sets remain valid, including swept supports and offscreen
light influence. Otherwise dirty the product. No stale timestamp relabelling; no source phase holding for timing.
Late work is bounded/coalesced and missed displayed timestamps are reported. Any slower radiance cadence is a later
age/error-qualified approximation with a current-state reference and costed fallback.

## Camera, reflection and numerical envelope

SKY-G uses one terrestrial sky frame: Earth-like radius6371km, radial height, atmosphere top100km, cloud support up to
18km and common planet/top/ground/Sun boundaries. Main full-sky cameras cover0–1536m with perspective/orthographic
views. Isolated above-family diagnostics do not qualify unrestricted full-sky flight. Optical profile coefficients,
aerosol albedo/phase/height and ozone choice are pinned assets; the old bounded Sun-only profile is a comparator.

Use stable radial-height/shell-root formulas, conservative tangent predicates and split GPU origins. A camera rebase
cannot reseed clouds. Fixed spherical chart IDs/cell adjacency deduplicate face edges and preserve source identities;
wind/pose export uses the declared spherical world mapping, never arbitrary angular texture scroll. Runtime source
transport/halo mapping must match shared W and the declared spherical chart or reject admission.

World-source demand covers main, independent reflection/environment, direct-light and ambient paths to their actual
finite planet/top/source terminals, including sources far outside the main frustum. Test cross-chart edges, horizon,
low Sun, upstream support and a visible patch whose ambient path reaches distant18km blockers. A hard4km cutoff and
one local cube are insufficient. Canonical virtual events do not imply one resident field per world cell. Far caches
advertise footprint/origin/time/domain/error and cannot erase clear gaps or depth correlation.

### Cost and profile admission

The [selected baseline account](CLOUD-PRODUCTION-BASELINE.md#ownership-schedule-and-allowed-tuning) and
[performance contract](CLOUD-PERFORMANCE.md) own current work/copy/lifetime accounting and optimization priorities.
The earlier per-age field, K48/A0 and probe ceilings in the Git-linked candidate are not production budgets.

Desired browser targets remain cloudCPU0.5ms/cloudGPU5ms, full-frameCPU8ms/GPU16ms and whole-browser512MiB;
native cloudGPU3ms/fullGPU10ms, with the earlier full-frameCPU5ms objective retained. These are proposed allocations,
not measurements. Specify CPU thread/critical-path/worker scope rather than claiming a host wait measures work.
P7 may qualify the complete **standalone cloud/air fixture** and measure its browser process. It cannot certify the
actual Thrum frame, rough-water/transparency cost or full product memory before P8 integrates those consumers.
Before production representation freeze, P3b/P4b includes a bounded rough-reflection/depth/transparency cost proxy;
P8 owns actual engine browser/native frame and memory admission. Unavailable devices/counters stay unqualified.
