# Graded examples

Evaluators start out lenient. Each verdict the owner overturns or confirms becomes an example here, so later reviews
match the owner's standard. Add new examples at the top, and keep about ten; drop the oldest when a newer one teaches
the same lesson.

Each example records:
- the milestone and item;
- what the captures showed;
- the evaluator's verdict;
- the owner's verdict;
- why the owner's verdict is right;
- the date.
