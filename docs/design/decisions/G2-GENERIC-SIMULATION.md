# G2 design: one registered simulation for the running game

5 November 2026. The original G2 correctness path ran in the game; **G2R speed and rewind are open**. C01/C02 still require checked identity, one atomic fixed tick and immutable leased endpoints. [Storage selection](G2-STORAGE-SELECTION.md) provisionally chooses owned columns; only integrated game measurements can qualify them.

## Ownership and public composition

`thrum-core` owns the checked slot/generation map, registered archetype columns, schedule, tick transaction, changed-slot journal, page leases and undo. A game owns component types, system callbacks, input/actions/rules and schema/quantization IDs. The V1 game keeps movers and statics separate; its four controlled actors retain velocity capability while idle. Engine production APIs name no V1 fields. Games register types and systems before the first tick; replacing a registration starts a new run until migration exists. A second game can compile without the example.

Component registration binds process-local `TypeId` to stable game schema ID and snapshot/undo operations. System registration binds stage, stable `SystemId`, dependencies, typed query and edit targets. The engine derives accesses, validates the declared union and compiles conflict-free waves. Structural edits and external resources need explicit capability. Callbacks see scoped queries and typed batches, never raw storage; sparse lookup checks `Handle`. Independent kernels may traverse deterministic storage order; order-sensitive rules and published lists use canonical slot order. Measure the ordering mechanism after archetype row moves.

## Tick, publication and replay

The input gate checks generic `InputFrame<GameAction>` identity, sequence, count and axes; game validation checks its action payload. Accepted frames remain pending until a tick commits. Each callback reads the committed state and writes to a reusable per-system typed edit buffer. Stage dependencies may read prior staged values only through the engine's candidate view; the engine must not publish or apply a partial candidate. Validate all outputs, identity edits, finite values where the game declares that rule, and structural conflicts before applying. Apply in stable order, update change ticks, consume inputs and advance the clock exactly once. Failed preparation retains the same due tick and admitted frames. Publication is optional: a busy page drops a view, never an authority tick; the next available page gets a full baseline. The game declares which registered components enter the read model; render and future replication consume its `SnapshotId`, dirty slots and structural journal. They never query a second authoritative world.

Prediction retains owned inputs and a caller-selected, preallocated history window of component preimages, structural inverses and relevant game resources; benchmark eight ticks. Undo restores slot/generation, ID map, free list, archetype rows, components and peer state in reverse commit order, then replays through the same serial schedule. A branch invalidates temporal history without mutating held pages. Canonical ordering at order-sensitive boundaries and stable merge order make serial/Rayon state, events, dirty lists and snapshot IDs byte-identical after churn and restore. Nondeterministic results must be recorded; cross-device float identity remains separate proof.

## Cost and migration gates

Batched columns and sparse page refresh measure 49–51 µs p95 at 10k and 500–519 µs at 100k; old eight-tick rewind is 3.63 ms. The [paired dense SoA spike](G2-STORAGE-SELECTION.md) is faster but omits generic costs. Avoid per-entity erased dispatch, full-static scans, per-tick allocations and cold worker injection. Registry and graph allocate at setup; typed buffers reuse high-water capacity. Measure complete game tick and eight-tick rewind at 10k/100k, allocation maxima, publication bytes and serial/parallel crossover. Engage parallel work only where measured faster.

The private store and changed-slot catch-up now run inside the **existing** V1 authority, with the window, iOS, browser and detached projection consumers on one page contract. Next remove full-static work, then add in-place undo and remove the copying hot history path. G2R passes only when the drawn game meets 25/300 µs tick and 100 µs/1 ms rewind p95 at 10k/100k with zero warmed allocations, serial/Rayon equality, byte-identical replay and `./dev check` green. G3 then builds the executing graph; `FrameHost` moves only after the display-link loop.
