# G3 decision draft: executing render graph

5 November 2026. **G3a design; execution remains unqualified.** C04, C06, C07, C12 and the [hardware-native decision](HARDWARE-NATIVE-ENGINE.md) govern this graph. CPU extraction copies a committed G2 page into an owned render packet and releases its lease before graph encoding; the graph cannot read the authoritative world. The platform owns the adapter, surface and display link. `FrameHost` stays in the game until G3b. The renderer owns GPU resources and execution. A game supplies handles and view intent, never pass internals. The synthetic scene stays in `examples/v1-game`; no fixture binary is added.

## Closure and execution

The platform constructs one immutable `DeviceCapabilities` record per adapter generation, including backend/vendor/driver, features and limits, tile and memory traits, display/HDR, CPU SIMD/core classes, thermal and IO providers. F2 selects the recipe from that record; graph closure consumes the selection. Passes cannot probe the device privately; raw Metal access is isolated behind one backend module. Registry digest, recipe and shader variant enter profiling and cache identity. A device reset creates a new generation and closes a new graph before drawing.

Setup declares resource descriptors (2D, 3D, cube and array textures; buffers), pass reads/writes, clear values, persistence class, required capabilities, queue class and a `record` closure. Closures receive checked resource views, an encoder/compute or render pass, and immutable frame data; they cannot allocate graph resources, query capabilities or retain transient views. Closure consumes F2's recipe and prepares portable at the same barrier. G3a executes current forward/shadow/tone passes; G3c adds portable GPU culling and indirect draws. Apple tile configures the same logical inputs/outputs as merged tile-friendly passes, memoryless depth/intermediates where supported and a measured raw-Metal escape hatch only where wgpu cannot express the win. The browser selects portable. Android tile and desktop-high remain post-V1; declarations must express them without changing game or frame APIs. Future sea/cloud consumers need compute-before-fragment, mipmapped arrays, 3D noise, wrapping and ping-pong histories, and async-compute-eligible passes; implementation remains parked until after G7.

The compiler versions each write; a read names its producer version, and multiple writes require an explicit edge. It topologically orders passes with declaration order as the stable tie-break, rejects missing producers and cycles, culls unused outputs unless they declare present, readback or future-history publication, and computes first/last transient use. A published Hi-Z pyramid stays live across frames. The executor reuses compatible allocations from a generation-scoped transient pool; aliasing requires disjoint lifetimes, exact descriptor compatibility and no outstanding submission lease. It derives load/store: first use clears or initializes; later use loads only from a prior producer; last use discards unless external/persistent/history/readback needs storage. Apple memoryless eligibility follows full in-pass lifetime and backend support; depth needed for Hi-Z is stored or resolved. Resize creates a new pool generation; old resources retire after GPU completion. Scene passes execute before G3b's late drawable acquisition; the present pass binds an imported surface only afterward. Automatic timestamps bracket render and compute passes; unavailable queries report absent. Epoch-skipped or time-sliced passes reuse compatible history or a neutral resource with age/reset telemetry. The quality governor never changes the simulation tick.

## Frame contract and hardware readiness

Every view carries jittered and unjittered projection, current and previous view-projection, C07 motion vectors, reversed-Z `Depth32Float`, reactive mask, exposure, camera cut and history reset. It records rendered sample time, interpolation alpha and the last image actually used for previous transforms; two display frames may share one simulation tick. Optional guides share the render sample. Render scale is separate from native output extent. Own TAAU and MetalFX consume this contract in G4. History compatibility keys include device generation, world epoch, replay timeline, view, visual revision, surface generation/resize and recipe. Source tick alone cannot establish adjacency; absent or incompatible prior images reset history.

The G3 mesh arena uses stable logical mesh handles and nonmoving backing spans reserved for the lifetime of a future acceleration structure; replacement allocates a new span and retires the old after dependent submissions. A bindless material table has one shader-visible layout for raster, compute and eventual hit shaders. G1 dirty structural/component sets become explicit GPU upload and future acceleration-structure refit/rebuild inputs; G3 does not build ray tracing. The upload owner tracks the last **applied** `SnapshotId` and replay timeline, not the last extracted page: only adjacent ticks on the same timeline use dirty sets. A skipped page or changed timeline triggers accumulated compatible deltas or a complete reconciliation against the latest leased endpoint, including despawns and visual changes. Timeline changes require complete reconciliation even when a divergent tick is numerically adjacent and the baseline page was skipped. GPU frustum and hierarchical-Z occlusion culling write compact visible instances and indirect draw commands. Occlusion can lag or be unavailable; a frustum-only path remains correct and counts its extra work. No CPU per-object draw loop is accepted as the 10k path.

Pipelines are compiled at graph closure. Live handles are keyed by adapter generation; persisted blobs use a stable compatibility fingerprint of adapter/driver/backend, feature and limit subset, recipe, compiler/cache format, shader source/specialization, layout and render formats. The on-disk cache is versioned and integrity-checked; a miss or invalid cache recompiles before the first draw and cannot change scene output. A two-day G3 spike decides **WGSL with Naga specialization** versus **Slang via passthrough** using required variant count, compile/cache time, Apple tile feature reach, portable/WebGPU output and cross-backend maintenance. No shader-source migration occurs until that comparison is recorded; either choice preserves the same material ABI and portable fallback.

## Cost and proof

The hot path performs no graph compilation, shader compilation, private capability probing or per-object CPU draw submission. Reuse command/resource arrays and bounded upload rings. Measure graph closure, cache hit/miss, transient peak bytes and aliases, pass GPU timestamps, culling work, draw count and CPU encode time in the one game at 10k. On the same physical iPhone, Apple tile must improve GPU time or bandwidth by at least 10% over portable with image difference inside the declared tolerance; both recipes remain measured from G3 onward. Verify load/store and aliasing under resize, device loss, skipped/timed passes, occlusion invalidation and held G2 page leases. An independent review covers the G2 publication, game content, C07 coordinates/time and platform surface seams before implementation.
