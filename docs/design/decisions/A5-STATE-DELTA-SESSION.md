# A5 decision: acknowledged state deltas and session admission

4 November 2026. **Selected design; unimplemented.** This closes [A0 N1](A0-N1-TRANSPORT-CODEC.md)'s V1 wire/session choices under [C13](../CONTRACTS.md). R4's full actor record is migration evidence. Game-declared schemas span native, browser and phone; local play pays no N1 projection, history or socket cost.

## Operating model and exact identities

N1 extracts **selected interest only** from W1's committed tick into peer-owned fixed-capacity quantized arrays, then releases the world lease. A game declares field ordinal, signedness, unit, range, width, error and required closure; a Rust schema macro generates descriptors and checked encode/decode into reused slices. Wire IDs and fields are sorted. Change ticks shortlist; quantized values decide difference from the base, including persistently deferred fields. Interest/priority selects optional work. Out-of-range or nonfinite values refuse or use a declared escape; no silent clamp.

Before state, the session checks match, epoch, sender, protocol/gameplay hashes and required content. The protocol hash covers schemas and packet bytes. Join stages a reliable baseline; chunks, digest and dependencies validate before atomic admission and `BaselineAck`. Each partition's quantized image becomes its first base. `baseline_id` names the transfer; one connection-wide monotonic, never-wrapped `image_id:u64` allocator names its partition images and later samples. Reliable and datagram envelope sequences are separate within an epoch. Contiguous `acknowledged_sequence` covers only reliable messages; datagrams have their own replay sequence and selective image ACK.

Both lanes use envelope kind `StateGroup` and a 56-byte little-endian payload header: `mode:u8, reserved:u8, actor_count:u16, lifecycle_count:u16, result_count:u16, event_count:u16, reserved:u16, partition_id:u32, interest_generation:u32, schema_id:u32, base_id:u64, image_id:u64, sample_tick:u64, resolved_through:u64`. Reserved bytes are zero. Mode 0 is a datagram delta: nonzero base, ≤32 actors, no lifecycle/results/events or watermark. Mode 1 is a reliable full partition image for baseline/generation repair: base zero, all fields and ≤32 existing 16-byte lifecycle records. Mode 2 is a compact reliable controller closure: one lossless actor, zero base/image IDs or lifecycle, ≤64 frame results and ≤64 events; exact controller state, result origins and watermark admit atomically. Complete groups cap at 8 KiB; only datagrams obey path MTU.

One result resolves an entire ordered `InputFrame`. It encodes increasing input-sequence difference (first from zero), `sample_tick - resolved_tick`, disposition byte (0 commit, 1 reject), optional reason, event count and optional first event ID. All integers except disposition use shortest-form unsigned LEB128 with overflow/range checks; rejection has no events. An event is its existing 40-byte identity/origin header plus `schema_id:u16, payload_len:u16, payload[payload_len]` (≤256 bytes). Each actor record starts byte-aligned with shortest-form unsigned LEB128 wire-ID difference (first from zero, later positive), then `ceil(field_count/8)` mask bytes, bit `i` for field `i`; excess bits are zero. Fields follow in schema order, least-significant bit first, with zero pad bits. Full modes require all mask bits; records never split.

The client reconstructs from the immutable base scoped to connection/partition/generation, validates the whole group in reserved scratch, then swaps at a replica barrier. Older samples drop; a missing base requests a full image. Malformed data changes neither replica nor ACK. V1 has a visual-pose schema (three signed 21-bit millimetre positions; three signed 20-bit velocities at 1/16384 m/s, with range refusal) and a lossless controller schema (three finite f64 positions/velocities, u16 health, three finite f32 held axes). Authenticated epoch and wire actor ID supply the binding. The owned actor renders from exact/predicted control; other actors use visual pose.

Datagrams need selective image ACKs. Protocol kind `StateAck=14` carries `partition_id:u32, interest_generation:u32, image_id:u64, sample_tick:u64`; epoch comes from its envelope. Only a retained image with newer ID **and** tick can replace the base; stale ACKs do not regress it and unknown IDs refuse. A candidate is **base plus exactly transmitted fields**. Deferred fields stay at base values and dirty relative to it, even without a new W1 change tick. Newer samples against that base repeat still-desired fields from earlier unacknowledged samples before adding others; if the cumulative set cannot fit, wait for ACK or send a reliable full image. This prevents packet reorder from reverting fields. Bounded RTT/jitter-sized image rings keep prior bases; exhaustion requests a full image or disconnects without blocking W1. WebSocket deltas reference last sent state and reset on disconnect. QUIC/WebTransport remain platform gates.

Lifecycle uses reliable mode 1. A generation change sends a full image **with** spawn/re-entry state or removal/detach closure; the client admits it atomically, drops old-generation datagrams and ACKs before new deltas. Required dependencies must fit one partition/group or admission refuses. Mode 2 couples routine results/events to exact controller state under the existing reliable ACK owner. One controlled partition plus four visual partitions of ≤32 actors retains 128 visible actors. A lossy delta never acknowledges gameplay execution. Reconnect takes a new full baseline; parked N1 credit/ledger work is untouched.

## Cost, reuse and first proof

At 20 Hz, 64 kbit/s permits **400 downstream bytes per publication**. The old 128 × 56-byte actor recipe costs 7,168 bytes before framing. With no events, one exact controller plus three compact results and reliable framing is about 198 application bytes. Four visual actors each need at least 16 packed field bytes, one ID byte and one mask byte, plus 120 bytes of framing: **192 bytes**. Together that is about **390 application bytes/publication, 62.4 kbit/s**. Client ACKs travel upstream; transport/TLS overhead and server control messages may still break the total downstream target. This is an analytical case, not a budget pass. Each extra nonempty visual partition adds framing, so the token bucket spreads optional groups across publications and reports sample age; mandatory results/lifecycle are never dropped for the target. More active actors/events need lower optional cadence or a wider profile. Sixteen 128-actor images at roughly 32 bytes each imply about 64 KiB per peer plus scratch; measure actual bytes, copy cost, residence, tails and allocation before selecting ring depth. No ordinary warmed tick may allocate.

Reuse review: [postcard](https://docs.rs/postcard/1.1.3/postcard/) lacks field deltas; [bitpacking](https://docs.rs/bitpacking/0.9.3/bitpacking/) targets integer blocks rather than short mixed records; [delta-pack](https://docs.rs/delta-pack/0.3.0/delta_pack/) documents allocating output and an exact-order base requirement. None supplies bounded selective-ACK admission. Select an audited bit cursor with generated schema code, provisional until measured.

First proof: generated V1 schemas and checked bit codec, independent golden bytes, fuzzing, then four 128-actor interests through the existing conditioner. Exercise loss, reorder, duplicate, baseline loss, lifecycle churn and reconnect; check no mutation on refusal, exact quantized admission, zero warmed allocations, bytes and CPU. Real native/Chrome/phone transport and visible correction follow. Codec-only benches cannot check off the V1 delta path.
