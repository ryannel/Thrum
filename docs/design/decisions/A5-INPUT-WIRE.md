# A5 decision: V1 input batch bytes

4 November 2026. **Selected for the conditioned input path; the first encoded no-socket run passes, while session and device proof remain open. Parked with the network track until after V1.** This specializes [A0 N1](A0-N1-TRANSPORT-CODEC.md), [A5 timing](A5-INPUT-TIMING-RECONCILIATION.md) and [C13](../CONTRACTS.md). The old fixed-record InputBatch in [NETWORK-SPEC](../NETWORK-SPEC.md) is historical. The protocol schema/version and game action table are pinned by the session handshake; a datagram receipt is never a gameplay result. W1 remains the sole authority.

## Packet and admission

Use the existing 64-byte application envelope with `InputBatch` kind for the first executable path. On QUIC/WebTransport input datagrams, connection state authenticates the peer and match; the envelope epoch and match must still agree, its message sequence is for packet observation, and its application ACK field is zero. Reliable session/control messages retain their own ACK semantics. The WebSocket fallback carries the same payload on an ordered binary message. The first application datagram budget is 1,000 bytes including the envelope, further reduced to the adapter's measured payload ceiling. Pack newest complete frames first, then as many complete recent frames as fit; never fragment or truncate a frame. If the newest complete frame does not fit, send that **whole frame** on the reliable control lane or refuse it under the negotiated profile. A larger batch may be split only on frame boundaries. Actual path MTU and browser delivery are unqualified.

The payload starts with `record_count:u8` (1–8). Each record contains `input_sequence:u64`, `actor_wire_id:u64`, `target_tick:u64`, three signed little-endian `i16` axes and `action_count:u8` (0–8), followed by ordered actions `{schema_id:u32, byte_length:u16, bytes}`. An action payload is at most 256 bytes. Wire IDs map through the session's checked actor table; they are never Rust handles. The game owns action schema IDs and field encoding. N1 structurally parses the entire bounded payload without allocating, then the game decoder checks **every** record's action schema, length, numeric value and semantic payload into bounded scratch before any frame reserves a future slot. A structural, schema or action-value fault rejects the **whole packet**, changing no timing window or W1 state. Once the entire packet is checked, individual frames may receive independent late, duplicate, conflict or ownership dispositions. The session binds each decoded record to its authenticated peer and connection epoch; sender-supplied bytes cannot choose those identities.

Axes encode finite normalized `f32` values by converting each value exactly to `f64`, multiplying by the `f64` value 32767, then rounding to the nearest integer with ties **away from zero**. Browser code must implement that same rule, not JavaScript's default negative-tie rule. `-32768` is invalid on decode; `-0` canonicalizes to zero. The maximum quantization error is about 1.53×10⁻⁵ axis units, excluding the smaller `f32` round-trip error. The resulting decoded values, sequence, actor, target tick and actions define an idempotent repeated frame. One-shot actions are never invented by a missing packet. An action encoder must produce its exact declared byte length; authoritative out-of-range values fail explicitly rather than clamp. Half-step and endpoint byte oracles gate the codec.

## Cost and qualification

Four empty-action records use `64 + 1 + 4×31 = 189` application bytes: about 11.3 KB/s per sending peer at 60 packets/s, before transport framing. Eight maximum-size actions in one frame require 2,192 application bytes, so that frame must take the reliable lane or refuse; its actions cannot be split into separate frames. This is distinct from the proposed 64-kbit/s **downstream state** target. The first conditioner retains fixed-capacity encoded packets and decodes once into checked frame values. No heap allocation occurs on the warmed held-control tick. A game action may allocate its owned `Vec` during decoding until its action frequency and retained-slot representation are measured; it must not impose that cost on empty held-control packets. The generic N1 codec owns only structural framing and axis quantization, never `SimAction` or a game's action layout.

The [first gate](../../evidence/v1-workload/A5-INPUT-WIRE-2026-11-04.md) replaces the four-peer conditioner's in-memory `Sample` packets with encoded bytes; it checks a 600-tick run, burst loss, malformed packet refusal, wrong epoch/actor, exact W1 positions, byte counts, CPU encode/decode and a warmed allocation assertion. A stdin parser fuzz target feeds arbitrary packet bytes through the complete structural decoder; an actual coverage-guided campaign remains open. A game-declared action round trip and an independent byte oracle check schema order and lengths. Session handshake, real QUIC/WebTransport/WebSocket adapters, result/ACK closure, acknowledged state deltas, client prediction and device bandwidth remain separate open gates.
