# A0 decision: N1 transport and replicated codec

3 November 2026. **Status: V1 target, unimplemented.** N1 transports W1's committed state and input outcomes; it never owns gameplay truth. One shared rules path serves local, listen-host and dedicated play. Stable IDs, sequence and tick semantics, schema compatibility and validate-before-apply admission remain C4 guarantees. The existing full-record R4 payload and fixed 8-input window are transitional evidence, not the V1 wire format.

Native uses [Quinn QUIC](https://quinn-rs.github.io/quinn/quinn.html); browsers use [WebTransport](https://www.w3.org/TR/webtransport/) where qualified. State deltas use datagrams against an **acked** baseline, with explicit baseline identity and recovery after loss. A reliable ordered stream carries results, events, lifecycle and schema/session control. A WebSocket fallback uses deltas against the last sent state on that ordered transport; it does not pretend to have datagram semantics. Browser/WebTransport availability and interoperability remain device/browser gates, not assumed support. Input batches carry recent `InputFrame` history for loss recovery; per-peer window size derives from RTT, jitter and tick rate rather than a fixed eight slots.

Games declare replicated components and quantization policy. A generated or derive-backed bit codec writes field change masks and packed values directly to a reusable buffer. Quantization declares range, units and error; outside-range authoritative data is an explicit encoding failure or a schema-selected escape, never silent clamping. The engine crate contains no game-specific `health`, `inventory` or `owner` fields. Session identity and schema/version hashes precede state admission. Change ticks drive per-peer candidate extraction, interest and priority accumulation; token buckets enforce a byte budget. Reliable events and results must reach the client end to end. Prediction stores the actual owned `InputFrame` payload, restores component snapshots, then resimulates; non-owned state interpolates from buffered authoritative samples.

The A0 conditioner models four peers at 100 ms RTT, ±20 ms jitter and 2% loss with a fixed seed. A5 qualifies correctness under reordering, duplicate, baseline loss and reconnect, then measures per-peer bytes, CPU encode/decode, allocations and visual snaps. Proposed first targets are ≤64 kbit/s downstream per client at 20 Hz and no visible correction snap in the representative game; these are not current claims. Keep the old codec behind a migration/test boundary until the four-peer loop replaces it. Fuzz untrusted envelope, codec and replica admission before opening a real session.
