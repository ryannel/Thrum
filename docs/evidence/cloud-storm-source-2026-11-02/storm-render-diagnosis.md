# Cb cap lattice diagnosis

2 November 2026. Read-only inspection of build `02374d3929095078`, its t=360 s Cb beauty capture, and the current source, optics, rest-carrier and view paths. The image has a dotted, nearly horizontal mesh localized to the new broad anvil; the lower column is comparatively smooth. This is an active visual failure. The planned held-source raw-q diagnostic and optical column samples were not yet available to this review, so the producer ranking below is provisional.

## Highest-probability mechanism: thin-cap view/detail alias

The pinned camera center ray traverses about14,895 m of the Cb source box. `view.integrate` uses96 uniform midpoints over that *entire* interval, about155 m apart on the center ray; the cap rays are similarly long. Cb source vertical voxels are181.25 m and the half-resolution material carrier cells are362.5 m. `coefficients` samples the level-0 64³ basis at unwrapped rest coordinates, corresponding to about50 m vertical base-noise texels and about11.6 m fine-noise texels from `coord*4.3`, before deformation. It then applies nonlinear threshold/erosion. There is no ray-footprint or step-footprint mip/antialias selection. A thin, horizontally spreading cap can therefore occupy only a few view samples while its sub-step detail changes rapidly. Regular midpoint sampling plausibly makes a stable dotted/striped screen pattern. The thicker core integrates more samples and hides it. Full1280×720 output increases pixels but leaves the96-step depth spacing unchanged.

The fixed light cache is a separate possible source of brightness pattern, but an opacity diagnostic that still shows this lattice would rule it out as the sole producer. The source's q grid could also contain a cap-band pattern, especially where liquid→ice transfer occurs; a raw-q optical column/image is needed before blaming the renderer alone.

## Credible secondary mechanism: invalid strained carrier

The carrier is advected once per .25 s at half q resolution in RGBA16F. At t=360 s it has undergone1,440 updates. `source.wgsl` backtraces `x−velocity(x)*dt` and trilinearly samples the previous rest texture whenever that point lies within the box; otherwise it seeds world coordinates. It writes `.w=1` for every cell. There is no check for missing donor correspondence, excessive stretch/compression, foldover, or half-float quantization before `optics.wgsl` interpolates the two rest states and samples high-frequency level-0 noise. In the Cb cap, updraft slows while radial outflow grows, so this is the most strained region. Half-float coordinate ULP near rest-coordinate magnitudes2–4 is roughly .002–.004, comparable with a10 m/step vertical advection increment of ~.003 in the normalized y chart. Repeated rounding can terrace or lock carrier motion and turn otherwise smooth q into a material-detail lattice. This risk is real in code but the screenshot does not prove it dominates the96-step alias.

## Decisive same-state isolation

1. Compare held-source **raw-q opacity** with current shaped-coefficient `mode=5` opacity at the same camera, time, Sun and resolution. If both contain the lattice, inspect q cap columns and source transfer/advection. If raw q is smooth but shaped opacity has it, the material/detail sampling path is implicated. If only beauty has it, inspect point-light cache/direct/ambient separately.
2. On a held source/rest snapshot, change only view steps (96→192→384) or midpoint phase. A lattice that shifts/refines with step spacing is quadrature alias. Compare the same cap ray's sampled `q`, shaped sigma and accumulated tau columns; a thin interval skipped between samples is decisive. A fixed world-space pattern in shaped sigma that survives a sufficient step sweep points toward carrier/noise detail instead.
3. If shaped sigma remains patterned after dense integration, compare the existing advected rest coordinates with the deterministic world-coordinate seed at the *same q* and inspect local rest-coordinate gradients/validity in the cap. A corrected image from seed coordinates isolates carrier strain; a change only from noise mip level implicates detail footprint alias. Do not use a beauty-only blur as a diagnostic.

## Minimal correction after identification

- If step/detail alias is confirmed, integrate the occupied cap interval with enough samples for its support and select a material-noise mip from the larger of ray-step and projected pixel footprint. Apply the same filtered coefficient convention to view, direct reference and lighting cache. This is standard footprint filtering/adaptive occupied traversal; merely changing output resolution or blurring final color does not address the sampled integral.
- If the carrier is confirmed invalid, retain its unwrapped rest coordinates but add actual validity/strain metadata. At half-resolution update, require valid donor support and bound the local mapping Jacobian (positive orientation, finite singular-value/strain range); reset only invalid regions to the deterministic world recipe and mark them reactive for shared view/light consumers. The existing always-one `.w` cannot establish correspondence. A float32-carrier comparison is a useful precision oracle before changing storage. This is a local repair, not a second wind authority or a final-image smoothing pass.
