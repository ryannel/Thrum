## Final narrow conformance addendum

Verified 1 November 2026 against CLOUDS.md SHA-256 `72d0bb77929a86aa947fcf1464d94ce536172e1426c1fa979814dd1361afef4c`.

The latest graph clauses explicitly split current integration, history/spatial resolve and full-resolution fallback into separate pipelines. Resolve marks rejected pixels in a cleared atomic-u32 bitset; fallback reads the original pre-media scene/depth plus optical inputs and writes only marked destination pixels without binding current/history images or sampling the destination. V1 orders publication before V4. This is coherent with the five-texture cloud layout and avoids requiring all optical resources and eight current/history image inputs in one pipeline. Whole-stage binding admission remains required, as the design states.

The bitset account is correct: 1280×720 pixels require 115,200 bytes (0.1099 MiB), and 640×360 reflected pixels require 28,800 bytes (0.0275 MiB). Their combined approximately 0.1373 MiB fits the stated transient planning headroom alongside the existing build/raw-media targets; it is real additional scratch, not another full-resolution S/T set. Scene-before/after colour, velocity and reactivity remain existing frame services explicitly counted in the whole-scene budget. Clearing, complete pixel classification, pass ordering and device limits still require implementation proof.

Finite cloud-off/attenuation-only/volume families remove unused bindings and producers; slot capacity is data/extents rather than a new variant per instance/frame. This preserves the prior feature-off and finite-pipeline closure. Default full V4 reactivity for cloud-modified pixels, unless combined background/volume motion is validated, correctly prevents a valid cloud vector from authorizing reuse of an independently moving background. It is consistent with conservative spatial-only joint-media overlap.

The new optical range bound is coherent with inverse-scale extinction: uniform world scale cancels in optical depth. `0.5 × 1.5 × 512 × sqrt(3) = 665.1075` bounds one source's diagonal, and four sources give approximately 2660.43, below 2661 and far below half overflow. The document correctly retains separate precision/quadrature gates and finite-prefix fallback; this is a range bound only.

Geometry visibility now explicitly covers the cloud-light sample domain. Outside-map visibility is unavailable absent a conservative unobstructed-path proof; Moon requires its own admitted geometry-visibility path. This closes the possible shadow-map coverage/source substitution leak while preserving the existing no-double-counting contract.

No new material contradiction was found in this final narrow check. The hash identifies the inspected design, not a built or qualified artifact. All runtime, visual, adapter and aggregate-budget evidence remains unrun.
