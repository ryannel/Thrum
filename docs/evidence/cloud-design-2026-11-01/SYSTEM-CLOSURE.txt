## Earlier capability dispositions remain intact

R1 still includes ordinary perspective/orthographic ground-accessible entry; flight/planetary remains separate. R2 still labels the first cumulus-like regime and selected light set honestly, allowing authored constant wind. R3 still keeps clip/group specifics local to this provider rather than universal APIs. R4 still independently binds retained reflection/attenuation with main appearance omitted. R5 still distinguishes one source disabled from all incident/emission inputs zero. The capability file is unchanged from the reconciled version reviewed previously, and the corresponding design sections preserve those dispositions.

No new contradiction was found in the focused changes. Daylight's preview mapping remains an explicit fixture/configuration choice separate from the concrete centroid trajectory; it must be supplied with the eventual preview rather than interpreted as a second cloud clock. Variable-wind recorded curves remain optional and cannot be used outside admitted coverage.

S1/S2 are resolved for this inspected design revision. Source/content correctness, ordinary and accelerated visual quality, actual trackpad response, numerical/cache errors, GPU scheduling correctness, memory/startup and sustained device performance remain unrun Q1–Q7 evidence. Closure does not promote any of those dimensions or authorize construction.
