# Cloud model review closure

1 November 2026. Scope: current `docs/design/modules/CLOUDS.md` only; reviewed content SHA256 `0048c6e40d5d8d1a16148610fdb0a3ceda9b3d9ad2d020eeab57b1e0db05ea8f`. This is analytical closure of MODEL-REVIEW.md, not source, visual, numerical or device qualification. No maintained edits/builds/bakes/GPU work.

**Disposition: review operators are closed at design level. No remaining representation or history-operator blocker identified.**

| Review point | Disposition in current design |
| --- | --- |
| 512m/128³ bandwidth and transport | Closed. Four-metre local cells preserve the selected optical bandwidth;15m transport need not be less than a density voxel. No transferred quality acceptance from the old2km study. Source/optical/morphology gates remain explicit. |
| Post-quantized V/L | Closed by the stated bounds on the **cooked continuous carrier** `v_i` used by runtime: norm<=2m/source-second, Lipschitz<=0.02/source-second. These are bounds on the decoded/interpolated/extended SNORM product, not merely exported node values. That is the required meaning of “cooked continuous”; an implementation that only checks pre-quantized samples would violate this contract. The midpoint and quantization perturbation bounds remain separate from external-source fit. |
| Actual history uncertainty operator | Closed. The compiler records gradients of actual quantized endpoint fields. `G*=max(Gi,Gj)*exp(Ld)` and the midpoint Lipschitz factor provide spatial bounds; map/composition/inverse, grid-resampling and half-storage errors propagate into coefficient uncertainty. Coefficient and projected-mapping gates reject independently of residual, representative discrepancy and variance. Conservative bounds that are unhelpful select spatial-only output. This is an operative declared policy, not a promise to add an estimator later. |
| Ideal residual versus actual runtime field | Closed. `abs(b-a)/d` is explicitly a diagnostic, not the exact RK2/grid-resampled derivative. Prior lookup uses runtime interpolation; current sampled-field reconstruction error is retained. The conservative max-extinction field remains distinct from that residual diagnostic. |
| Residual ratio units | Closed. The formula uses world residual/floor/extinction and explicitly scales all by `k/lambda`, or allows an entirely local calculation. Earlier per-instance `sigma_world` defines the contributing stamp quantity; do not substitute summed joint extinction into an individual stamp's ratio. |
| Correspondence gate and lifetime | Closed. Q1 explicitly says1 **local metre**; world/pixel mapping includes instance scale. Initial history additionally caps0.25world seconds and7.5source seconds, resets at interval boundaries, rejects unsupported/missing generations, and retains prior swept support/tombstones for vanished density. Full source residency does not extend correspondence automatically. |
| Half prefix uncertainty | Closed. The difference's half-storage uncertainty radius is now **bounded above** by `eps(A)+eps(B)`, with direct finite-path evaluation when its allocation is exceeded. Separate filtering/quadrature errors remain separate. |
| World versus source time | Closed. Ordinary centroid advection uses world seconds and internal flow uses `ds/dt` through the chain rule. Timelapse samples recorded source/trajectory as an authoring preview with static receivers; it explicitly makes no64x physical-world/force claim. History retains actual preview/source/presentation samples. |

The projected0.5media-pixel, coefficient0.1scale, local-change/discrepancy0.2, optical-depth0.1 and1local-metre values remain **proposed, unrun thresholds**. Closure establishes that an implementer has actual bounds, propagation and rejection/fallback operators to follow. It does not establish that useful temporal reuse survives those conservative bounds, that any source passes the optical/morphology gates, or that the assembled workload meets startup/frame/memory targets.
