# Superseded design, not delivery work

Root superseded this proposal on3November2026 after independent review. Full-cell128-slab interval certificates and32F manual prefix reconstruction add a substantial new subsystem. The coupled proof does not need arbitrary AP prefix subtraction: full clear/unshadowed rays can reuse the four-LUT result; disjoint spans already have a bounded direct air producer. Removing subtraction closes cancellation structurally. None of the proposed certificate machinery was implemented or GPU-qualified. The scalar counterexample remains useful adverse evidence, not a selected runtime acceptance gate. Reconsider segment reuse only if measured assembled cost justifies a separately reviewed optimization.

### 6.1 Selected AP numerical path — correction after independent P2 review

**Select RGBA32F for both AP prefix atlases**, not RGBA16F. Use eight `textureLoad` taps and explicit F32 trilinear weights; no optional float32 filtering. Add one RGBA32F certificate atlas32×32×64, one logical32³ layer per view. Certificate texel at lower cell index stores `(eS_maxRGB,eT_maxRGB,status,0)`; terminal index31 has status0. Status1 means a finite conservative certificate for that whole closed interpolation cell, status0 means direct fallback. No interpolated status or crossing of the two packed view tiles is permitted. Physical grid coordinates/depth mapping and each view's real ray bundle remain unchanged.

The selected unit-Sun reference is the continuum clear-air transport equation with the analytic profile and the **frozen declared T/MS interpolants** as its source inputs, zero far/ground terminal. AP envelopes certify approximation to this reference; they do not prove the physical accuracy of T/MS LUTs, the Hillaire MS closure or a cloud-light approximation. Those retain separate qualification/error records. At each AP cell, the certificate producer encloses all ray origins/directions and prefix lengths in that cell, including reflection's varying interface origin. Outward interval arithmetic encloses the compensated spherical geometry, height/profile/phase and the full range of touched T/MS interpolation cells (min/max over all contributing texels plus their declared numerical bounds). Profile preparation stores64B of outward global RGB min/max bounds for the two declared T/MS interpolants in the reserved SceneTable quality range; these bounds include storage/filter uncertainty. Inspect at most32 touched texels total per slab; larger ranges use those global bounds in O(1), accepting a looser envelope rather than an unbounded scan. These are range summaries, not new sampled textures. It must not substitute the centre ray or eight vertex residuals for a cell-interior bound. A crossed atmosphere/ground/branch boundary that this producer cannot enclose returns status0.

Bounded certificate construction: split the normalized prefix path `[0,1]` into128 equal subintervals. On each, interval-evaluate nonnegative RGB extinction/source over the full ray-cell parameter box; include ozone/profile breakpoints by their min/max ranges, not by dropping discontinuities. With segment-length interval `[l-,l+]` and coefficient bounds `[k-,k+]`, `[j-,j+]`, a valid cell transfer enclosure is `T∈[exp(-k+*l+),exp(-k-*l-)]` and `S∈[j-*phi(k+,l-),j+*phi(k-,l+)]`, where `phi(k,l)=(1-exp(-k*l))/k`, `phi(0,l)=l`. Compose these nonnegative interval transfers in order with outward rounding. This bounds quadrature **and** ray-grid interpolation against the stated reference without assuming a smooth centre-ray error. It may be loose; that causes fallback, not a narrower invented error. Invalid profile inputs/NaN/overflow or unbounded touched LUT range yield status0. The GPU interval helper must provide directed outward enclosures for basic arithmetic and transcendentals under the selected implementation's documented accuracy; where that is unavailable, emit status0 (the direct path still operates). Correctness never depends on an undocumented one-ULP WGSL transcendental claim.

Let `[Sref-,Sref+]`, `[Tref-,Tref+]` be those whole-cell enclosures. Let `Svertex-/+`, `Tvertex-/+` be extrema of the eight actually stored F32 prefix values. Store upward-rounded scalar RGB maxima `eS=max_c(0,Sref+_c-Svertex-_c,Svertex+_c-Sref-_c)` and similarly eT. Thus any exact convex interpolation of these stored vertices differs from the reference anywhere in the cell by at most eS/eT. Stored vertex F32 conversion is already covered by comparing **stored** extrema to the reference enclosure; certificate conversion is rounded outward. If the certificate itself cannot be stored finitely, status0.

At query time compute nonnegative F32 weights, renormalize their sum, and reconstruct S/T. Add explicit filtering/arithmetic bounds using `gamma_n=n*u/(1-n*u)`, `u=2^-24`: `eFilter<=gamma_64*maxAbsTap + 64*2^-149` per channel, plus the certified coordinate-to-weight arithmetic error times the sum of tap magnitudes. The coordinate term is an interval evaluation of the actual normalize/index/fraction operations, not eps32 independent of distance. Any ambiguous lower-cell index includes both adjacent cells' certificates/taps or falls back. Combine cell and arithmetic errors into endpoint intervals `Sa,Sb,Ta,Tb`; do not clamp negative/greater-than-one stored results into validity. All following interval operations include their own outward F32 arithmetic bounds.

For one **same-ray** prefix pair with increasing physical distance, require finite endpoints and `Ta.lower>=1e-3`. Derive interval enclosures `Tab=[Tb.lower/Ta.upper,Tb.upper/Ta.lower]` and `Sab=[(Sb.lower-Sa.upper)/Ta.upper,(Sb.upper-Sa.lower)/Ta.lower]` only after proving the subtraction numerator nonnegative. Every RGB `Tab` interval must lie within `[0,1]` and every `Sab` interval within `[0,+inf)`; no post-division saturation hides a violation. The zero-length case returns exact identity without AP lookup. Segments that fail any condition take direct fallback.

Radiometric acceptance is in **unexposed scene-linear cd/m²**. Multiply the unit-Sun Sab interval by the validated `E_TOA_RGB` interval, not by an arbitrary exposure-relative epsilon. Let candidate L be the midpoint estimate, error `eL` the maximum distance to its interval endpoints; accept per channel only if `eL <= .01 cd/m² + .005*max(0,L-eL)` (relative term uses a certified lower magnitude). Let candidate t and error et similarly satisfy `et<=1e-5 + 1e-3*max(0,t-et)`. These are selected AP reconstruction budgets, not observed image acceptance. Pre-exposed storage/use multiplies L and its absolute error by the same preExposure; the .01 cd/m² threshold must also be scaled. No source-independent unit-Sun tolerance is silently called a radiometric bound. Terminal transmission error is separately charged: with a finite terminal radiance bound LtermMax, require `eL+et*LtermMax <= .01+.005*max(0,L-eL)`; without such a bound, AP subtraction is unavailable. Sun-disk/very bright terminal rays generally take direct integration.

**Fallback is the existing reanchored32total air-only profile march**, split at closest planet approach and biased toward the low-altitude end of each monotone segment; distribute32 by length, never omit a segment. It evaluates one ray and carries the analogous32-slab interval enclosure/error record, avoids prefix subtraction/division and never fires cloud Sun queries because the scheduler proves this segment free of local shadow/fog/cloud. Its own quadrature/roundoff error must satisfy the same radiometric/T budget to publish a *qualified* clear segment. If neither AP nor direct32 qualifies, return `quality-unavailable` with the computed provisional direct result and error, not false numeric readiness, silent refinement or clear identity. Caps/work stay finite; root may inspect provisional POC images but cannot call them passed. Segments beyond32km and Env rays use this same direct method. Full main clear sky may use SkyView plus diskT once under its separate declared LUT qualification.
