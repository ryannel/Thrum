- `j_cloud = sum_constituents sigma_s * D * (P0*Tcloud0 + .5*P1*Tcloud1) + sigma_s*.5*LmeanUpper(h,muSun)*(.2+.8*A_current)`.
- Liquid phase is .8HG(.8)+.2HG(-.2); ice .85HG(.85)+.15HG(-.15). P1 multiplies each eccentricity by.5. View extinction is ordinary sigma_t; MS octave modifies source only.

## 4. Exact analytic fog producer

One E1-supplied fog record: centre `[-1400,120,900]`, identityR, radii `[1900,500,1800]`, beta_t=.0007RGB/m, albedo.9, g=.3. It is declared world-anchored, not secretly advected with root-height wind. Queue pose/density edits through the same source clock/barrier; use one frozen interpolated pose for all readers. The overlap fixture moves centreY to1200/radiusY800; it is the same producer, not another shader. Outside planet is enforced by common ray terminal/clip, not a second flat-ground fog mask.

`u=diag(1/r)*R^T*(o-c)`, `v=diag(1/r)*R^T*d`, with unit world rayd. Density `f(s)=max(0,1-|u+s*v|²)`. Let a=v·v, h=−u·v/a, p=u+h*v, delta=1−p·p. If delta>0, ellipsoid roots are `h±sqrt(delta/a)`. Clip roots against requested cell/ray/opaque-planet terminal. On `[A,B]`, m=(A+B)/2,L=B−A:

`I = L*(delta-a*(m-h)²-a*L²/12)`.

For stable nonnegative evaluation use the algebraically exact quadratic Simpson form `I=L*(f(A)+4f(m)+f(B))/6`; evaluate f with `a*(r-(s-h))*(r+(s-h))`, r=sqrt(delta/a), clamping only roundoff-level negatives. Full chord independently gives `4*delta^(3/2)/(3*sqrt(a))`. This is an exact polynomial integral, not an8-step shadow approximation. `tau_fog_RGB=beta_t*I`, SunT=exp(−tau); average view cell coefficients use beta_t/s*I/ds even if only part of that cell intersects fog. Incident illumination still samples within the cell and has ordinary quadrature error.

Pure API: `fogPoint(profile,x)` returns f/sigma_tRGB/sigma_sRGB/g; `fogSegment(profile,o,unitD,tMin,tMax)` returns `{valid,reason,interval|null,I_metres,errorI,tauRGB,T_RGB,averageSigmaT,averageSigmaS}`. Empty proven support returns identityT/zeroI; uncertain numerics returns invalid. Zero-length segments return identity without division. Caller supplies the actual clipped interval; its E1/V3 wrapper adds source/profile IDs, sample time and validity interval. The helper has no world-clock/GPU/renderer dependency.

Validate finite positive radii (selectedGPUprofile25..8000m), orthonormalR, unit directions, beta_s≤beta_t, coefficients≥0 (selectedbeta_t≤.01/m,g∈[−.95,.95]). CPU uses F64; WGSL uses FMA/closest-approach plus an explicit FP error bound. For a tangent classification uncertainty deltaErr, missed full-chord tau is bounded by `(4/3)*max(beta_t)*deltaErr^(3/2)/sqrt(a)`. Accept zero only when that bound≤1e-5; otherwise return invalid. Negative I beyond propagated arithmetic error is invalid, never a clear sentinel. The pure helper owns this math; callers own planet/fixture clipping and same-time pose. This producer can be implemented first without changing runtime viewers.
