fine hierarchy on upper heads **and side shoulders**, visible across front/side/top routes. The implementation:

1. globally sorts all candidates by one preferred direction;
2. greedily accepts the first site;
3. accepts later sites only if spaced1.45–1.8mean-radii from their nearest already selected neighbour;
4. stops after the first six L1 or four L2 sites.

That creates a compact connected patch around the preference. It supplies no surface-sector/coverage objective to

the problem; unrestricted search among the remaining candidates still takes the high-scoring compact cluster first.
