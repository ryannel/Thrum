# Final bounded code closure addendum

2 November 2026. Read-only check of the duplicate configuration path and loaded-build URL identity in the updated `src/bench.js`, `src/scene.js` and `serve.py`. No WebGPU, visual or performance claim.

- **Duplicate configuration rebuild: closed in code.** `configure()` still increments `configurationVersion` for a new request, but returns immediately when `configurationRunning` before setting `configurationPending`. The active loop observes the newer version, discards a superseded candidate and applies the latest selection. Its `finally` no longer schedules an extra rebuild for a version it already consumed. A request made while an observation/reset has `busy=true` still sets `configurationPending` and is drained afterward. A rapid-toggle running receipt remains useful, but the prior duplicate-rebuild path is removed.
- **Loaded-build drift detection: substantially closed for ordinary edits between requests.** `/` redirects to `/build/<contenthash>/index.html`. Relative JS imports, shader fetches and `identity.json` stay under that hash; the server returns 409 for stale non-index resources and redirects a stale index to the current build. `Scene.create()` rejects non-200 shader responses. This prevents a normal edit between separate resource requests from silently mixing versions and ties the receipt identity to the selected URL.

**Exact-byte caveat:** `serve.py::do_GET` computes hashes from live files, checks the requested hash, then delegates the resource open/read to `SimpleHTTPRequestHandler`. A concurrent file write between validation and that read can still serve bytes under the preceding hash. The scheme detects most drift but is not an atomic immutable snapshot. For strict capture provenance during active edits, serve the already hashed bytes (or a pinned immutable build tree) and compare their hashes, or coordinate a no-writer capture window. This is a narrow evidence-integrity qualification, not a cloud/provider architecture gap. `identity.json` itself is a versioned request and remains within the same limitation.
