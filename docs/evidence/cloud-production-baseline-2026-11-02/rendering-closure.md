The source technique lineage had already been read in the earlier review. **Verdict: no remaining plan-level rendering blocker in this bounded delta.** This is not a runtime or M2 admission.

| Prior finding | Verified resolution and consequence |
| --- | --- |
| BSM point tail was inferred from a full column | The selected BSM is now strictly receiver-only: a valid query behind all four tapped columns receives `exp(-b^i*tau_column)` per tap before visibility filtering, Sunward of all fronts receives one, and mixed/interior/outside queries use a full secondary Sun ray through *all* intersected cloud support. The map stores front/back/tau/valid in RGBA32F with `textureLoad`; no undefined partial-tail reconstruction or local/map double counting remains. A 32-sample column or direct-ray cap may select an admitted coarser complete-support quadrature or report invalid, never silently omit upstream casters. The two multiple-scattering octaves reuse the same cloud tau at factors `b^0,b^1`. |
| Near/far overlap or lost clear-air prefix | Far integrates `[200 m, terminal]`, near `[0,min(200 m,terminal)]` and the affine operators compose once. Terminal before 200 m makes far identity. The near mask explicitly includes cloud, fog **and cloud/geometry-shadowed clear air**; only an unshadowed cloud/fog-free near interval uses the clear LUT prefix. Boundary crossings invalidate relevant history. This closes the shadowed-air shaft that the first delta read found missing. |
| All-cloud AO invalid under independent ages | Baseline playback is synchronized by whole episode and world clock; differing ages are baked birth times. Arbitrary event retiming/cloning is unsupported. The 16³ R8 accessibility stream is keyed by episode revision, global time knot, event ID, complete occluder/pose revision and grid, separate from shareable density endpoints. `CLOUDS` and `CLOUD-PERFORMANCE` repeat the limitation and key consequence. |
| Ambient units and direct Sun ownership | `L_sky_mean_upper=(1/2π)∫upper L_clear_sky dΩ` explicitly excludes the direct Sun disk; `j_amb=σs·0.5·L_sky_mean_upper·(0.2+0.8 A_baked)` accounts for the upper hemisphere under isotropic normalized 4π phase. The 0.2 floor and one extra cloud MS octave are labelled authored look controls. Direct Sun disk is excluded from the lighting cube and applied once as a boundary/direct-light source. For joint view rays the top-of-atmosphere terminal supplies **unattenuated** disk radiance; the integrated air/cloud/fog intervals provide all attenuation. A fully clear unshadowed ray may use sky-view instead of that integral, never in addition. |
| Fog Sun factor was unnamed | `T_fog(x,Sun)=exp(-Σ∫σt,fog ds)` is RGB over every intersected bounded fog volume, using the same coefficient sampler as view transport. Analytic supported segments or 32 total complete-support samples produce it; inadequate sampling chooses error-qualified coarser quadrature or invalid. Air LUT, cloud BSM/direct path, fog path and geometry visibility each multiply once at one point/time. Fog ray work is separately counted and cloud-induced use charged to the 5 ms cloud budget. |
| View/history memory and hidden cost | 36 B/pixel for S, RGB T, 32-bit depth/motion guide and ID/flags, across current and two ping-pong sets for 320×180 far, 640×360 near, 320×180 reflection: `345600 × 36 × 3 / 2²⁰ = 35.596 MiB`. Full 1280×720 resolved RGBA16F color and R32F geometry depth add `10.547 MiB`; total `46.143 MiB`, leaving `1.857 MiB` inside the stated 48 MiB pool for bounded fresh scratch. One ordered GPU queue reuses the sets after encoded final readers; external capture/async readers require additional charged physical allocations. Whole simultaneous reservation is 200 MiB, not the earlier 184 MiB. The cost ledger explicitly charges complete interior Sun rays, shadowed air/fog integration, fog rays and native fresh silhouette work to cloud 5 ms, leaving 0.8 ms only for unshadowed clear air/composition. `CLOUD-PERFORMANCE` requires actual old/new, worker/IO, upload, process/driver and fixture measurements. |
| Environment/reflection validity | All six 32² cube faces share one source/Sun/air/**fog/geometry/anchor** generation. They use the same BSM-behind/direct-interior classification and direct-only terminals, exclude the direct Sun disk, publish clouded SH9/roughness without recursive surface irradiance. Low-roughness reflection has its own 320×180 view/history and applies the eye-to-interface operator once. `CLOUD-PROOF-ACCEPTANCE` retains independent mirror, rough-reflection proxy and eventual real-water gates. |

The remaining limits are stated qualification, not missing render choices: low-Sun 2048 km BSM footprint and complete-column sampling error, coarse 16³ accessibility/32² cube appearance, 4 Hz authored-frame interpolation, near/far reconstruction, simultaneous resident source pages, and full shadowed-media/direct-ray cost. The baseline gives direct/reference comparisons, invalid/fallback semantics and stage gates for these. The 5/16 ms and 512 MiB browser targets, native 3/10, and five-family beauty/motion are **unrun**. Nothing in this delta justifies treating them as passed or adding a new algorithm experiment before the selected path is built and measured.
