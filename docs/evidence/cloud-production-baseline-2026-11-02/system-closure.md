## Former blockers

**Interior Sun visibility: closed at design level.** The revised BSM stores front/back depth and full-column tau. A query fully behind every valid tap uses that total; a query before all casters uses clear visibility; mixed/interior/outside support takes a complete sample-to-Sun secondary cloud march. The latter crosses all intersected occupied source intervals, including offscreen upstream blockers, and never adds a BSM tail to a local prefix. The BSM's32-sample cap now explicitly covers the complete column or uses admitted coarser quadrature/mip, then invalidates/direct-falls back if insufficient; it may not truncate upstream casters. This defines the previously missing producer/consumer operation. Sample count and quality/cost remain P3b/P7 qualification.

**Two adjacent transport gaps: closed at design level.** The near mask now includes cloud/geometry-shadowed clear air and composes an explicit `[0,200m]` prefix with a disjoint `[200m,terminal]` far operator, with terminal-before-boundary identity and history invalidation. The Sun factor now defines same-position `T_air` from the common LUT, `T_fog` across the full union of bounded fog supports (with sample-cap invalidity), and geometry visibility once for direct source/receivers/reflections. These rule out silently losing near shafts or borrowing view fog as Sun-path attenuation.

**Retired critical-path experiments: closed.** The queue, acceptance and performance records now use authored episode continuity and observed source/loss instead of runtime branch/shear editing; ordinary far footprint mips versus resolved tests instead of a mandatory far-transfer codec; selected BSM/direct-interior/one-octave light instead of mandatory selective-light or fitted-bank competition. The changed encoded48MiB/source64MiB pool and expanded48MiB view pool are consistent across baseline and performance, totaling **200MiB**, not the former184MiB. The view ledger accounts three sets of far/near/reflection ray targets plus720p resolved color/depth, with remaining scratch named; actual physical/process peaks remain unrun.
