## What changed and why

The previous plan kept critical source, wind, branching, far-field and light choices as research competitions. That
was unnecessary for the requested production look and coherent authored motion. The selected baseline is Houdini
FX22.0.459 SOP/sparse Pyro/VDB/Karma -> all-five3D optical animation -> ordinary sparse brick/mip/frame-window playback,
with offline shared wind, exact poses and persistent episode IDs. Runtime adds no wind. Different ages are authored
birth offsets within a synchronized story; arbitrary live branch/phase/wind editing is optional.

The complete path selects Hillaire air LUTs and RGB aerial T; two-lobe phase/one extra MS approximation octave;
baked all-cloud ambient accessibility; cascaded full-column Beer shadows for behind-cloud receivers and complete
secondary Sun rays inside cloud domains; ordered RGB media; current environment/SH9 and independent reflected rays;
disjoint near/far intervals and independent per-view temporal/spatial reconstruction. The fixed structure and
producer-consumer ownership table prevent an attractive isolated effect from becoming a substitute for the system.

Nubis³/Decima, current Epic UE5.8 and Smolder2026 establish **separate production precedents**, not proof of this exact
assembly. Epic SVT remains explicitly Experimental: its interpolation/prefetch API is reference material, not shipped
adoption evidence or a dependency. No private engine code, new third-party assets, bulk bake or tool purchase was used.
The original research, oracles and rejected implementations remain recoverable in Git and their dated evidence.

## Dispositions

| Consequential finding | Final resolution |
| --- | --- |
| Whole-column Beer data cannot determine an arbitrary interior Sun tail | Removed the inferred tail, rather than inventing a depth codec. Behind-all-caster receiver lookup only; mixed/interior/outside uses complete secondary rays through all occupied intervals. Both map and ray caps cover complete support or invalidate, never silently omit blockers. |
| Near/far overlap and shadowed clear-air prefix | Disjoint[0,200m]/[200m,terminal] integration. Near demand includes cloud/geometry-shadowed air; unshadowed clear prefix alone uses LUT. |
| Fog-to-Sun producer missing | Defined RGB complete-support fog optical integral using the same coefficient sampler, bounded quadrature/analytic path, explicit invalidity and common factor ownership. |
| All-cloud ambient cannot share by master/frame or arbitrary phase | Separate episode/global-time/instance/all-occluder keys; synchronized whole-story playback. Density shares only exact immutable matches. |
| Source frame transform, representative regimes and IO not fixed | Explicit inverse-current-pose/common-grid interpolation; Cu/Cb, dense Sc/St and thin Ci before source-format freeze. Requested presentation-page bytes and actual1x/16x/64x throughput, not prefetch count, qualify streaming. |
| Angular ambient/direct Sun duplication | Normalized upper-hemisphere sky mean with0.5 isotropic factor; direct disk excluded from lighting cube. Joint transport attenuates unattenuated solar boundary once. |
| Views exceeded32MiB and hid lifetime/cost multipliers | Explicit36B/pixel/current+ping-pong ledger46.143MiB in48MiB pool; single ordered queue reuse. Total pool proposal200MiB; full process512MiB still unqualified. Charge interior rays/shadowed air/fog/native fresh work to cloud5ms. |
| Companion gates still required retired experiments | Canonical scope/capability mechanisms, DoD, performance, sources and queue aligned. Local growth/renewal/breakup, height wind, all five families, weather, consumers and adverse visual gates remain required. |
| Restored code table delayed early views/light | Views start P0/P3a, minimal lighting P3a/P4a; full lighting P3b and reconstruction P4b. Narrow internal units map to actual Thrum roles at P8. |

Reviewers found no remaining plan-level blocker in their scoped deltas. Optional custom lifecycle/wind/branch/flow,
far transfer/deep compression, fitted scattering, selective/subgroup lighting and neural/Gaussian routes are outside
the required build path. Revisit only after a measured baseline deficit and explicit decision.

## Remaining execution gates

Houdini production installation/license is selected but not verified locally; no purchase/install is authorized or
performed by this planning task. Actual five-family sources and their normal/accelerated structural motion remain
unbuilt. Start with a<=2GiB pilot, prove recoverable masters/storage before larger caches, then qualify all source
regimes, current-time streaming and coupled cost before a broad library. No cache or unseen VDB is accepted content.

The200MiB pool and M2 WebGPU5ms cloud/16ms fixture/512MiB process and native3/10 targets are proposals, not forecasts.
The old local one-Cu M3 cost failure remains adverse historical evidence. P7 qualifies a standalone fixture; P8 alone
qualifies actual Thrum/water/transparency/full-product budgets after engine dependencies exist. Source/reference
images and personally watched1x/16x/64x motion are required progressively; this document review supplies neither.
