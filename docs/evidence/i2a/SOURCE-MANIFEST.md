# I2a source manifest primitive

2 November 2026. This is a **pure metadata identity proof**, not verified candidate capture or accepted-source admission. The [source specification](../../design/FOUNDATION-SPEC.md#1-source-format-and-identity--select-one-ordinary-file-language) defines `SourceRevision = SHA-256(JCS(TreeManifest))`; the native durable root/outcome transaction remains the authority for acceptance.

`TreeManifest` validates the v1 project UUID, 100,000-file and 16 GiB-per-file bounds, portable path aliases and file ancestors, duplicate root-record IDs and duplicate declared dependency-root strings. It sorts files and roots once by UTF-8 byte order, independent of platform collation. The fixed v1 representation includes format, project ID, declared roots and each file's path, `file` kind, length, SHA-256 and nullable root-record ID/type. The digest writer emits known object keys in RFC 8785 order and canonical string/decimal primitives directly into SHA-256. A separate JCS serializer checks the complete fixture and control, quote, backslash, Unicode and number primitives. Changing only source formatting changes the supplied file hash and revision; declaration order does not. F3 still owns the meaning and closure of dependency roots, nested IDs, schema fields, required references and migrations. The current constructor accepts supplied file hashes; it does not verify any source or staged bytes.

Reproduce correctness with `RUSTC_WRAPPER= rustup run 1.99.1 cargo test --locked --offline -p thrum-source`. The local metadata-scale probe uses `RUSTC_WRAPPER= rustup run 1.99.1 cargo test --locked --offline --release -p thrum-source measure_maximum_manifest_metadata_cost -- --ignored --nocapture`; it consumes the digest through `black_box`. On a local arm64 macOS 26.6.2 release test, one 100,000-entry run reported 26.9 ms fixture generation, 18.2 ms validation/sort and 44.6 ms JCS/SHA-256 emission; the entry structs alone occupied 11.2 MB by `size_of`, excluding path strings, indexes, allocator overhead and the test harness. Current `manifest.rs` SHA-256: `ddbe717055d3c6ff1e1ab63683205098114cb01f88a4551caf4ddb146538290d`; `Cargo.lock`: `d0ade2fa8c6b5858e0acfdc49087f682b20692f6b912e6fbd2e69c3664cd03e8`. These are local synthetic metadata costs, not edit-to-ready latency, disk throughput, peak RSS or a device qualification.
