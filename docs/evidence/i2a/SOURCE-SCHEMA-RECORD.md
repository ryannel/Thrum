# I2a first source schema record

2 November 2026. **One fixed descriptor record, not a registry or source admission.** `thrum-source::schema_json::parse_schema_descriptor` reads a supplied `core.schema` schema 1 JSON byte slice, at most 16 MiB. It directly decodes the common envelope and fixed `schema.targetType`, `schema.targetVersion`, `schema.fields` and optional extension prefix. Known-key visitors refuse duplicates and unknown values before retaining their payloads. The sorted field array refuses a 129th element before deserializing it. A checked record retains at most 128 active fields and derives their canonical signatures plus its immutable type-version hash using the separately tested [hash primitives](SOURCE-DEFINITION-HASHES.md).

Fixtures cover a text and typed required-reference descriptor, a changed text bound producing a changed definition hash, duplicate/unknown fields, wrong reference policy, duplicate or unsorted field IDs, invalid large version, trailing input and an over-limit array whose extra value is malformed. The ignored release probe parses 256 maximum-size 128-field descriptor records from one prepared byte slice in 30.60 ms on the local arm64 macOS host. Reproduce with `RUSTC_WRAPPER= rustup run 1.99.1 cargo test --locked --offline --release -p thrum-source measure_256_maximum_schema_records -- --ignored --nocapture`. The timer includes record parsing, field/type hashes and returned descriptor allocation; it excludes stage I/O and byte hashing, project declarations, history consistency and game-record validation. One local run is not a latency distribution or device qualification.

The parser has no source-admission authority: a future staged-tree validator must verify declared path/record identity, check both source-carried histories against active descriptors, validate game records and required references, and compare the prior history under the durable root generation. A conservative peak memory reservation for dense/adversarial descriptor records remains open. `RUSTC_WRAPPER= ./dev check` and `RUSTC_WRAPPER= ./dev check-docs` are the repository gates for this checkpoint.
