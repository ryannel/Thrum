# I2a field-meaning lineage comparison

2 November 2026. **Pure registry-history proof, not F3 validation or durable source admission.** The [source-capture design](SOURCE-CAPTURE-DESIGN.md#general-registry-selection-before-implementation) calls for every admitted `(type ID, field ID)` and its mechanical meaning to remain in source-carried history. `thrum-source::compare_meaning_histories` checks two strictly sorted, duplicate-free slices. Every prior ID must remain with the same 32-byte signature; an active ID may retire, but a retired ID cannot revive. Candidate additions are allowed. A branch missing an admitted ID must merge the current history before admission.

The comparator validates both orders, then uses a merge cursor. It takes O(prior + candidate) comparisons and allocates no heap memory. The signature is opaque to this function. A later descriptor validator must derive it canonically from interpretation-bearing fields, ensure history agrees with active descriptors and bound entry counts. A later durable adapter must read the prior history from the **current admitted root** under its generation compare-and-swap. No caller can establish those facts with this pure function alone. Imported registries and their authority roots also remain future work.

Unit fixtures cover additions, retirement, missing prior IDs, changed signatures (including a changed-unit surrogate), revival, stale branch union, duplicate keys and unsorted input. `RUSTC_WRAPPER= rustup run 1.99.1 cargo test --locked --offline --release -p thrum-source measure_meaning_history_100k -- --ignored --nocapture` measured 1.689 ms for one 100,000-prior-entry comparison with one added candidate entry on the local arm64 macOS host. This timer excludes fixture construction, parsing, staged-byte verification, descriptor/signature derivation and durable storage. It is one local cost sample, not a latency distribution or platform qualification. `RUSTC_WRAPPER= ./dev check` and `RUSTC_WRAPPER= ./dev check-docs` are the repository gates for this checkpoint.
