# I2a comparison of two parsed source histories

2 November 2026. **Pure comparison, not an authenticated source root.** `thrum-source::history_json::compare_carried_histories` applies the same monotonic field and type-version rules as the earlier [slice proof](SOURCE-MEANING-HISTORY.md) directly to parsed `RegistryHistory` entries. Generic internal views keep one implementation of those rules. No 100,000-entry adapter vector is built. The candidate must retain all prior field IDs and signatures, never revive a retired ID, and retain all prior `(type ID, version)` definition hashes. It may add new entries; a stale branch missing an admitted entry refuses.

Fixtures use two separately parsed history records and cover additions, missing or changed fields, revived retirement, missing or changed type versions. The ignored local release probe constructs two 14,500,266-byte buffers, each with 100,000 field entries and one version entry. It timed a same-history comparison at 2.53 and 1.96 ms in two local runs on the arm64 macOS host. A direct test-binary child run reported 59,686,912 bytes maximum process RSS with both buffers and both parsed vectors live; this includes fixture construction and a subsequent over-limit rejection, excludes filesystem cache, and does not include a descriptor or game-record buffer. Reproduce with `RUSTC_WRAPPER= rustup run 1.99.1 cargo test --locked --offline --release -p thrum-source measure_maximum_field_history -- --ignored --nocapture`. These are local development samples, not a latency distribution or device qualification.

The caller must obtain the predecessor from the **current admitted root** under the same generation precondition as root publication. This function cannot establish that provenance, verify staged paths or supply a physical reservation for the complete validator peak. `RUSTC_WRAPPER= ./dev check` and `RUSTC_WRAPPER= ./dev check-docs` are the repository gates. The first source-carried registry profile remains unchecked in the [Build Plan](../../BUILD-PLAN.md#parked-retained-in-git-history).
