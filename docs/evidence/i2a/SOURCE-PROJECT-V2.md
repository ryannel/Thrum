# I2a project schema 2 declaration

2 November 2026. **One fixed project record, not verified staged-tree closure.** `thrum-source::project_v2_json::parse_project_v2` directly decodes a supplied `core.project` schema 2 JSON record at most 16 MiB. It keeps `project.format:1`, admits up to 4,096 strictly sorted scene/game record paths, up to 256 strictly sorted game-schema paths, one exact `schemas/history.registry.json` path and a nonempty sorted list of canonical entry-scene IDs. Including project and history, the maximum declaration is 4,354 engine records. It rejects duplicate or unsupported keys, unsafe paths, wrong reserved-path roles, wrong project identity/version, and excess array elements before parsing their values. The earlier schema 1 empty-scene bootstrap remains separate.

Fixtures cover a scene plus marker record and schema path, wrong path role or nested path, duplicate/unknown keys, wrong project version, unsorted paths, trailing data and a malformed element beyond the record count. An ignored release probe parsed a 121,866-byte declaration with 4,096 record paths and 256 schema paths in 698 microseconds on the local arm64 macOS host. Reproduce with `RUSTC_WRAPPER= rustup run 1.99.1 cargo test --locked --offline --release -p thrum-source measure_maximum_project_declaration -- --ignored --nocapture`. This is one local parse sample, excluding staged file I/O, hashes, actual membership, schema/history consistency, game-record validation and durable admission.

The staged-tree validator must verify all declared paths and reserved-file membership, resolve entry-scene IDs, and prove the declared schema/history records against their exact staged bytes. No accepted source root follows from this parser. `RUSTC_WRAPPER= ./dev check` and `RUSTC_WRAPPER= ./dev check-docs` are the repository gates; the first source-carried registry profile remains unchecked in the [Build Plan](../../plans/BRIEF.md#parked-retained-in-git-history).
