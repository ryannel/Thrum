# Staged first-profile registry proof

2 November 2026. `validate_staged_registry` reads only the exact-byte provisional stage. It verifies captured length and SHA-256 again for `project.json`, every declared `core.schema` record and `schemas/history.registry.json`. The schema 2 project declaration must list existing scene/game and schema paths; staged reserved paths outside those declarations refuse. Prefab and asset-sidecar records refuse in this profile. Active descriptors are sorted by target type and checked against the carried field and immutable type-version histories. Project, schema and history records must have distinct stable IDs. A nonempty external dependency-root declaration refuses.

The project and descriptor inputs reuse one byte buffer, cleared between records; that buffer drops before the borrowed history input is read. Descriptor summaries remain live; no copied history-entry vector or generic whole-tree JSON value is kept. This avoids a fresh input allocation for each declared descriptor while keeping at most one registry input buffer live. This slice has no physical parser/graph peak reservation and does not compare the history to an authenticated prior root. Scene and game records are only checked for declared **membership** here; they can contain invalid bytes. Entry-scene and game-reference resolution, manifest derivation, source-editor round-trip and durable admission remain open.

`RUSTC_WRAPPER= ./dev check` passes the workspace checks. Local fixtures cover a valid registry, a changed descriptor meaning against unchanged history, old-stage survival after a source edit, missing and unlisted paths, unsupported reserved records, nonempty dependency roots, duplicate registry IDs and duplicate target types. The ignored Rust 1.99.1 release probe validates the five-file staged registry 1,000 times in 55.373542 ms total after buffer reuse, compared with 55.2075 ms before it. This difference is within run noise; the benefit is avoiding repeated descriptor input allocation at larger counts. This is a small source-edit-path observation, not a maximum-profile memory, device or whole-capture measurement.
