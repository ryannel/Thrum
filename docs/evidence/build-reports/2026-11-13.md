- A background turn is stopped when a non-shell tool call has been open 15 minutes (`stopped_turn` names it).
- `migrate --branch --worktree <path>` migrates one worktree with pre-migration commits, holding only that module's lock; plain `migrate` no longer waits for runs once main is migrated.
