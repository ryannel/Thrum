## Findings

**S1 — Suggestion, verified by code inspection: preserve float bits in the exact-readback witness.** In `crates/thrum-render/tests/graph_kinds_support/gpu.rs:362`, the consumer converts sampled `rgba32float` values to `vec4<u32>` before the CPU comparison. A positive fractional perturbation smaller than one can disappear in that conversion. The fixture writes exactly representable integers and uses unfiltered texel reads (nearest cube samples), so this is a weakness in the witness, not an observed texture defect. Preserve the sampled float bits and compare them with the expected float bits to make the test's exactness explicit. The reviewer prepared that stronger variant without editing production files; see [witness source](M1-review/gpu.rs), [entry point](M1-review/exact-bits.rs), [support](M1-review/exact-support.rs) and [build command](M1-review/exact-build-command.json). The stronger witness passed every float bit in all 36 combinations and all three mips; see the [result](M1-review/exact-bits.log). Thus no actual value error was found, and this remains a test-hardening suggestion.

No Must Fix found in source inspection or independent runtime proof. No earlier M1 review was present. The prerequisite APPLE-TILE M2 is `done`.
