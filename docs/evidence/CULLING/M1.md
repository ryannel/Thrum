# CULLING M1 — mesh-bucket Occlusion

11 November 2026. Target: this M3 Max, Metal. GPU runs hold the repository's `gpu` lock.
Implementation and Metal correctness evidence below; exact-baseline qualification is blocked by disk space.
No new speed, motion-quality, Chrome or simulator claim.

## Implementation and oracle

History on the member route is indexed by `InstanceRecord.ids[0]`, not member-list position. The final cull
clears the next side and atomically sets logical-slot bits, including when classes share a word. Each class's
depth pipeline shares the forward module, vertex entry, primitive and depth state. Both lists bind the bucket
member/table inputs; the prepass draws its own list, and the colour pass draws the final list in bucket order.
Direct remains the bucket-ordered oracle. The pyramid, depth tolerance and footprint widening are unchanged.

## Metal checks

`cargo test --locked --offline -p thrum-render --test visibility_buckets` passed all eight tests
([log](m1-buckets.log)). The renderer's resolved mode is asserted at preparation and in the counts.
The mixed cube/open-mesh fixture compares every logical frame through ordinary/mirrored class flips,
deactivation, physical compaction, reactivation, a previously hidden slot's reveal, and resize from 320×180
to 481×271. It repeats on a newly requested device (generations 61 and 62). After the initial history seed,
Occlusion draws 122–421 slots versus Frustum's 302–900; all compared pixels match. Pixel readback and public
count readback repeat the same submitted inputs before committing history, so their list inputs agree.

The depth witness has a planar front at local z = −0.731 and a referenced degenerate rear triangle at z = 1
that fixes its bounds without adding pixels. It is flush with a later bucket's occluder. Origins are
`[-400.37, 1.13, 400.71]` and `[4000.37, 1.13, -4000.71]`, with in-plane rolls 0 and 0.3 radians.
The mesh wins 6,724–6,745 tied pixels in Direct and keeps every one with the derived tolerance.
The rasterizer interpolation allowance remains an assumption, not a proved bound.

margin. This bounded search found no footprint witness, so no no-widening mutant is claimed. Widening remains
derived and unfalsified here; this search does not establish that it is unnecessary.

## Full-route observation and remaining qualification

The first release every-tick run from `2c370314` stopped at tick 866: Frustum differed from Direct by two
pixels ([failure](m1-field-first-failure.log)). No rendering/culling code was changed in response.
An isolated endpoint, a 66-frame lead-in and an exact 866-frame prefix subsequently matched; the
[prefix replay](m1-field-prefix-replay.log) halved Frustum on 859/866 ticks. This does not explain the initial
failure. The subsequent [complete named target](m1-field-full-pass.log) passed all 1,930 ticks through the first
cut from `bb3fe56c`: Frustum and Occlusion each match Direct exactly, no counts are missing, Occlusion never
exceeds Frustum and halves it on 1,918/1,930 ticks. The initial two-pixel failure remains unexplained and
retained for review; no rendering/culling code was changed to make the rerun pass.
The [affected renderer regressions](m1-render-regressions.log.gz) passed 242 library, nine legacy visibility
and eight M1 tests. These bounded passes do not settle the full-route observation.
