# CULLING M3 — valley route qualification

The implementation is present, but qualification is incomplete. In particular,
the native mesh oracle has a retained byte mismatch; a visually imperceptible
difference does not satisfy M3.4. See the [investigation](M3-investigation.md).
M3 remains `in_progress`; this page does not claim the gate has closed.

## Explicit-gradient candidate rejected at 2fd5cf06

The resumed [item checker](M3/qualification-2fd5cf06/items.txt) passes M3.1,
M3.2, M3.5 and M3.6, but fails M3.4 and M3.10; the repository gate consequently
refuses the missing exact-baseline proof. These results belong to clean
`2fd5cf063800447260bfe14143922879b5948074`, before the rejection below.

The native mesh route differs at six SDR pixels at tick 255. Its
[raw Direct and Frustum bytes, receipts and comparison](M3/qualification-2fd5cf06/failure-summary.json)
are retained. A separate unchanged-shader run with Metal API and GPU shader
validation enabled differs at 18 scene-linear pixels at tick 251. Its
[complete log](M3/qualification-2fd5cf06/metal-validation.log) reports validation
enabled and no validation error before the exact-oracle panic. This does not
rule out an implementation or driver defect.

The [exact verifier](M3/qualification-2fd5cf06/exact-record.json) stops at
APPLE-TILE's `portable-sdr-approach`: [4,859 changed pixels](M3/qualification-2fd5cf06/exact-comparison.json).
No retained reference was modified. Evaluating explicit gradients before the
Sun search therefore neither establishes stable Direct output nor preserves
the owner's exact image. The candidate is rejected, and `synthetic.wgsl` is
restored byte for byte to its pre-candidate blob
`a8d8926fc15c2dfcaaab6d1f8b1779ae7609d2d3` from `64c81cd2`.

The plan's exact-baseline stop rule requires a blocked handoff. The proposed
continuation is diagnosis that preserves the existing material sampling and
the exact references, rather than adopting this candidate or refreshing a
baseline. See the [handoff](M3-handoff.md). No post-revert device qualification,
merge or new builder pass is claimed.

## Clean-source qualification at 64c81cd2

The [literal item checker](M3/qualification-64c81cd2/items.json) passes M3.2,
M3.5, M3.6 and M3.10. Chrome's cube and mesh routes match Direct at every
checkpoint with the requested modes resolved. The temporal cycle passes. The
[exact verifier](M3/qualification-64c81cd2/exact-record.json) passes both native
matrices (38 + 4 comparisons) and four Chrome sets of 481 records each.

M3.1 fails on the cube route at tick 379 (12 differing Occlusion pixels).
M3.4 fails on the mesh route at tick 180 (18 differing pixels between two
independent Direct hosts). [Original raw images, same-time recaptures and
receipts](M3/qualification-64c81cd2/recapture-summary.json) preserve both failures.
All twelve recaptures in each failure equal the original first Direct image;
world ticks do not advance, and alpha/exposure values stay fixed. The differences
are shaded terrain, not visibly missing props. A separate original mesh run on
the same source passes all 361 frames on both native recipes, demonstrating
intermittency rather than a repair.

A scoped candidate now evaluates explicit UV gradients at fragment entry,
before Sun-shadow searches, and shares them across the three material samples.
It preserves the sampler, anisotropy, content and strict comparisons. Its cost
account is four gradient scalars live across the Sun search, with one derivative
pair reused by three texture reads. This candidate is unqualified; the
[investigation](M3-investigation.md) distinguishes observations from hypotheses.

## Implementation and target proofs

The valley requests Frustum at launch, with Direct and Occlusion still selectable.
`THRUM_VALLEY_MESHES=on` selects the bucket route for the same entities. The native
oracle compares every submitted tick 180–540 against Direct on Portable and
AppleTile, and retains a second independently prepared Direct host. Chrome
compares its own submitted checkpoint pixels against its own Direct. Both
oracles assert the resolved mode; neither permits a capability fallback to count
as culling. Temporal sampling has a separate full-cycle target. Compute reads the
same material buffer that forward rendering binds.
