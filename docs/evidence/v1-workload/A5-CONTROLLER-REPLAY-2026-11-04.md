# A5 shared-rule controller replay, 4 November 2026

Four clients now predict their own complete controller values in the same 10k-entity game used by W1. W1 and the clients call one extracted control/action calculation and one position integrator. Each client stores the **decoded wire value** of authored axes, its exact input origin, up to eight inline actions and a complete predicted controller in 64 tick-indexed records. Confirmed groups remain separate. On divergence, a client restores the complete confirmed state and replays later authored inputs; all peers share one 1 ms return-frame budget and shed speculation to confirmed state on exhaustion. No collision or external resolve command affects these four fixture controllers.

Focused tests compare the pure rule with W1 for impulse, damage and held ticks; a fractional-axis plus two-action frame traverses the actual input codec and matches the predicted state and committed origin. Invalid axes/actions leave the branch unchanged. A wrong committed origin or direct binding mismatch drops the branch. Independent review found and prompted fixes for wire canonicalization, exact input identity, a shared rather than per-peer time budget, and reporting fallback as a valid degraded state.
