# A5 encoded conditioned input, 4 November 2026

The same 10,000-entity/1,500-moving four-peer V1 world ran 600 fixed ticks on an Apple M3 Max with Rust 1.99.1 release. The conditioner now stores actual `InputBatch` application-envelope bytes, delays/drops them, then structurally decodes and game-validates the entire packet before reserving future slots. The game declares `Impulse` and `Damage` action layouts outside the generic N1 codec. W1 remains the sole gameplay admission and commit owner. This is an in-memory byte path, not QUIC, WebTransport or a client replica.

| Observation | Result |
| --- | --- |
| One release 600-tick run | 2,400 packets sent, 55 dropped, 2,330 delivered, 15 in flight; 452,856 application bytes sent and 439,626 delivered. Four final authoritative positions matched the independent held-axis trace; 2,380 frames admitted, zero due misses. Fixed-seed 2–4 tick one-way delay and 2% configured packet loss. |
| Per-sender application rate | 113,214 bytes over 10 seconds, about 11.3 KB/s or 90.6 kbit/s upstream before transport overhead. The 64-kbit/s target is for **downstream state**, which this does not measure. |
| CPU and allocation | Two release process runs observed tick p50/p95 49/58 and 61/79 µs under variable local load. Encode/decode totals were 115/382 and 144/476 µs respectively across the 600-tick runs. Three 20-sample Divan medians were 34.24, 29.4 and 29.0 ms per complete run; the first run ranged to 81.62 ms, so no speedup or regression is claimed against the earlier 28.62 ms local baseline. The complete run made 131 benchmark-thread Rust allocations including construction/teardown; the counting-allocator assertion remained **zero across 500 warmed ticks**. |

An independent little-endian byte oracle covers one game-declared action, and boundary tests cover quantized axes, reserved `-32768`, every truncated prefix, trailing bytes, unknown action schema and checked actor mapping. The production packet-receiver test sends a wrong-epoch envelope and a valid-first/unknown-schema-second packet; both refuse before the first future slot changes. Existing 600-tick burst-loss and world reconnect tests still pass through the encoded path where applicable; the reconnect test separately exercises W1/N1 epoch replacement. A stdin fuzz target for the envelope and structural input parser builds and accepts a 1 KiB arbitrary-byte smoke input; no coverage-guided fuzz campaign has run. Strict Clippy and the full repository gate are recorded by the landing commit.

Open: real session authentication/handshake and transport adapters, payload-ceiling discovery, full-frame reliable fallback, result/ACK closure, acknowledged state deltas, client prediction/reconciliation, browser/iPhone multiplayer, fault-run latency and sustained device bandwidth. The fixed 256-byte conditioner packet storage is sufficient for this empty-action fixture, not a general action capacity claim.
