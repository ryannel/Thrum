# A1 provisional simulation slice

3 November 2026, local arm64 macOS, Rust 1.99.1 release profile. The private SoA adapter holds 10,000 entities and moves 1,500 each fixed tick. A 600-tick warmup preceded 3,600 serial tick observations. This path uses preallocated tick-stamped touched-row candidates; Resolve validates them before Publish. The first implementation copied all columns each tick; replacing that path reduced its observed tick p50 from 50.5 µs to 20.6 µs and p99 from 63.9 µs to 26.6 µs on this host. The 100/s churn and four full snapshot-copy test observed zero scoped heap allocations for 600 ticks; a separate 32,000 unique-ID replacement test found zero allocations after setup, but this is a same-thread count and not the complete engine host.

The copy cost supports A2's consumer-specific extraction; full-record snapshots are not a network or render representation. This does not select custom SoA over hecs/bevy_ecs, qualify rollback, include physics/AI, run parallel jobs, test Wasm or measure a named phone. It also does not measure a complete four-peer game or GPU frame. The [A0 storage spike](../../design/decisions/A0-WORLD-STORAGE.md) remains open.
