Each conformance receipt names its actual source checkpoint; the target runs reproduce the
unchanged crowd folds and the expanded vectors.

neighbours 2.21× from 2,000, while the grid table grows from 4,096 to 16,384 entries. Build
clears and scans that table. Its measured growth is 2.8–3.0× across these repeats.
This accounts for work that scales independently of accepted neighbours. The chronological
quarter-regression and clock flags are false. Each row names the last comparable row from
the previous retained record, plus the earlier repeat when present, with ratios and flags.
The previous record is pinned by Git revision and SHA-256 and checked again by `costs`.
The regression test reproduces the review's 1.19 → 1.751 ms case and requires its flag.

`measure` produces records. `costs` checks completeness, compiler and measured-source identity.
Completion depends on the complete source-matched record.

targets, local sources, locked package identities/checksums and shared build settings.
Each record saves this input manifest. The [regression receipt](M1/source-identity-regression.json)

runtime changes still invalidate the key. Seven focused tests cover feature/edge changes,
checksums, workspace lockfile unions and plain or qualified profile overrides.
