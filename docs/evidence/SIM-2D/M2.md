# SIM-2D M2: ordered spatial queries and the Mixed trace

The circle index now supports circle, axis-aligned box and capsule overlap, plus nearest-k.
Overlap order is oversize slot, cell row, column and slot; nearest order is squared centre
distance then slot. Retained buffers and stable byte-counting passes prepare a bounded
wide-query scan. Validation precedes replacement; query-domain errors preserve the index.

The [test receipt](M2/tests.json) covers the independent full-enumeration oracle, hand-worked
touching and degenerate geometry, tiny-scale underflow, domain refusal and a swept projectile
that crosses an enemy while its endpoint misses. The oracle changes table capacity independently
of scene geometry. The minimum-cell-size domain query spans billions of cells per axis and
finishes by scanning bodies. The counting allocator observes warmed calls without asserting a count.

The [Mac serial](M2/mac-metal.json), [Mac forced-parallel](M2/mac-parallel.json),
[Chrome Wasm](M2/chrome-webgpu.json) and [iPhone simulator](M2/ios-sim.json) receipts reproduce
both retained traces at 2,000 and 5,000 bodies for 3,600 ticks and 10,000 for 36,000 ticks,
including corrected replay and wire routes. Native debug runs cover both 2,000-body traces.
Mixed reports oversize bodies and swept-only hits; forced-parallel runs report actual steering
chunks. Each receipt records its source commit, source key and executable hash.
