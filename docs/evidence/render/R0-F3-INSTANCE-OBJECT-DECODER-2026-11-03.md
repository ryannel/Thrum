# Inactive render instance structure and typed-edge facts

3 November 2026. The private shared F3/F4 render decoder now parses instance source objects into canonical binary identity, mesh and material UUID references, authored initial translation/quaternion and finite signed scale. It accepts the strict map grammar in any key order. Every object kind now uses one identified-object helper for decoded recognized-key duplicates, valid-ID diagnostic locators and anonymous repeated-ID fallback. The helper skips decoding the final raw ID when ID itself is duplicated.

The instance's mesh and material UUIDs are **unresolved typed edges**. This slice checks their spelling and type only; it does not search a namespace or infer product support. Translation is finite and within the closed ±1,000,000 m authored extent. The quaternion uses the same exact source-band predicate as camera and transformed bounds. Scale may be negative, zero or signed zero when finite. A mesh-dependent transformed-box predicate belongs after global duplicate and typed-edge closure; the parser deliberately accepts a finite large scale that may later fail that bound. W1, not this source object, owns committed runtime pose.

Two focused object tests cover fixture facts, signed/zero and large scale, invalid quaternion, canonical reference spelling, reordered keys, known-field priority, recognized escaped duplicate fields, repeated escaped unknown keys and positional-array refusal. A fifth collection test exercises canonical instance error order and provisional edge projection. Fifteen combined render-object/collection tests and targeted Clippy pass. Independent adversarial review found no remaining instance semantic or lifetime defect after the unknown-key diagnostic contract was clarified.

The [shared decoder contract](../../design/research/R0-F3-F4-SHARED-DECODER-API-2026-11-03.md) now states the efficient refusal rule: recognized schema-field duplicates report before semantic fields; unknown decoded keys report one final Unknown refusal even when repeated. This still rejects every unknown and duplicate unknown source. Distinguishing unknown-key duplicates would require a separately charged key set or a potentially expensive rescan, with no source-validity gain.

This is inactive structure only. The production F3 namespace/edge pass, deferred mesh-bound closure, operation account, F4 selected-pin cook and renderer are open. Camera and instance structure currently run the complete transformed-box predicate solely for the exact quaternion band; the instance deferred bound will run it again. Before activation, measure the combined many-instance path and decide whether one shared prepared quaternion/norm representation or a quaternion-only predicate avoids material repeated work without creating a second validity rule.
