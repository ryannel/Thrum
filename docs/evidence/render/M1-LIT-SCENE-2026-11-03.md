# M1 lit synthetic scene — 3 November 2026

Bounded running proof for the [M1 foundation](../../design/decisions/M1-RENDER-FOUNDATION.md).
The existing prepared scene now renders real directional light, metallic-roughness
material response, emission and opaque depth. This does not complete M2 clustered
forward/CSM or qualify an engine frame budget.

## Fixture and verification

Apple M3 Max, Metal, macOS 26.6.2 (25G83); Rust 1.99.1
(`58cf8f9c3`), wgpu 30.0.1, debug test build. Synthetic revision 2 uses
10,000 static cubes (100×100), one instanced draw, 120,000 triangles, a fixed
orthographic camera and one unshadowed directional source. Receiver-to-source
input is `(0.4,-0.6,-1)`, normalized once; perpendicular-receiver RGB illumination
is `(4,4,4)` in diagnostic working units. Two material rows use red rough
dielectric and blue roughness 0.3/metalness 0.2. Only default texture layers are
admitted. The output is 1920×1080 linear RGBA8Unorm with Depth24Plus, Less/write,
clear-depth one and discard at pass end; there is no display transform.

The explicit real-adapter test passed. Pixel checks compare sampled 65×33 output
against an independently evaluated f64 Lambert/GGX/Smith/Schlick formula. They
cover nonzero material/instance rows, zero/maximum roughness, metalness changes,
source disabled/back-facing, emission, near-antiparallel grazing input and both
near/far submission orders. Padded-row readback, stale generations, pending-slot
refusal, repeated timestamp batches and timestamp-disabled behavior also pass.
The 10k capture covers more than 100,000 non-background lit pixels. A native-scale
480×360 crop was inspected: distinct red/blue rows and differently illuminated
cube faces are visible. This is a static procedural diagnostic, not game-art or
motion-quality acceptance.

One bounded read-only Sol High review found a real near-antiparallel f32
half-vector underflow. Source-invariant half-vector/Schlick preparation now uses
f64; scaled Smith cosines keep the remaining denominator bounded away from zero.
The reviewer independently checked the revised arithmetic, extreme directions
and 20,000 scalar pairs; the actual GPU regression then passed. Full material
hemisphere-energy/reciprocity conformance remains open.

## Isolated cost

Final run: five warmup pairs, then 32 sequential measured pairs. Each timed render
is followed by host completion, a separate timestamp resolve/readback submission,
then an untimed render. Pixel capture happens after measurement. There were no
concurrent benchmark jobs. The named GPU interval is `synthetic forward opaque`;
no zero/invalid counters were substituted.

| Interval | Minimum | Median | p95 | Maximum |
| --- | ---: | ---: | ---: | ---: |
| GPU opaque forward + depth | 0.118625 ms | 0.119708 ms | 0.124417 ms | 0.129208 ms |
| CPU encode + timing finish | 5.208 µs | 11.042 µs | 18.375 µs | 21.167 µs |
| CPU encode, timing omitted | 4.792 µs | 9.333 µs | 17.333 µs | 35.416 µs |

CPU intervals exclude encoder construction, submission, polling and readback.
They are short noisy samples, not an overhead ceiling. GPU intervals exclude
CPU preparation and display. Synchronized testing prevents a frame-pacing or
throughput inference. No matched 1080p unlit baseline was collected, so no speedup
is claimed. Logical persistent uploads total 1,920,000 instance bytes, 160 material
bytes, 208 view/source bytes and four default texels. Colour is 8,294,400 bytes;
depth has 2,073,600 samples with backend-selected physical storage. Peak residency,
allocator costs and sustained thermal/energy behavior are unmeasured.

## Reproduction and identity

Run from the repository root; a real adapter is required and absence fails:

```sh
PATH="$(dirname "$(rustup which --toolchain 1.99.1 rustc)"):$PATH" RUSTC_WRAPPER= \
  cargo test -p thrum-render --offline --locked --test gpu -- --ignored --nocapture
```

`THRUM_RENDER_CAPTURE` may name an absolute scratch PPM path to retain the final
raw-linear readback. Captures are reconstructible; no binary capture is promoted.
Native CPU tests passed (12 tests; one separately opted-in GPU test).
`cargo check -p thrum-render --offline --locked` passed for
`wasm32-unknown-unknown`, `aarch64-apple-ios`, `aarch64-apple-ios-sim` and
`aarch64-linux-android` with the pinned compiler. These are compile checks, not
browser/mobile pipeline or device tests. The integrating work owns the complete
repository gate; unrelated concurrent lint-policy edits are outside this proof.
