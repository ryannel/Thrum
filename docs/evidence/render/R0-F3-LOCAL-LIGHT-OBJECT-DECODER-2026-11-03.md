# Inactive render local-light source facts and exact luminance

3 November 2026. The private render-v1 local-light object decoder now emits canonical ID and unchanged authored position, candela intensity, linear Rec.709 unit colour and emitter radius. It applies no four-light recipe cap, target packing restriction or renderer-owned pose. W1 will own committed positions; V3 will own light transport after F3/F4 closure.

The source predicate interprets `Y=(1063R+3576G+361B)/5000` and the ±`1/1,000,000,000` tolerance as exact rationals over decoded finite binary64 values. A certified binary64 interval decides clear cases, with an 18-limb fixed stack fallback for boundaries. This is independent of the older constant-light source predicate. Two Python `Fraction` boundary examples demonstrate that the older ordered-f64 expression can disagree with exact admission. The implementation retains accepted colour bits; F4 normalization and representation residual remain undecided.

Six predicate tests include 36 independent Python rational boundary vectors, 30,000 fixed-denominator integer-oracle cases, subnormal/exponent cases and one-blue-ULP endpoint transitions. A separate Python `Fraction` process agreed on 30,000 more cases. Independent adversarial review checked the interval error bound, early >16 rejection, exponent/limb widths, carry and endpoint comparison and found no defect; 100,000 further rational samples found no mismatch. Eight object tests cover authored facts, signed zeros/subnormals, extent and type refusal, exact-vs-rounded boundaries, escaped fields and canonical diagnostic priority. One collection test covers UUID ordering and provisional projection suppression. Targeted tests and Clippy pass.

In a standalone local Darwin arm64 Rust 1.99.1 optimized kernel probe, medians of five samples were 3.93 ns for normalized colours and 3.92 ns for broad RGB values (zero fallback in each 100,000-case fixture), versus 18.30 and 23.49 ns for always-exact limbs. Deliberate endpoint fixtures used fallback for every case and measured 22.88 ns, versus 19.54 ns limbs-only. These are predicate-only measurements, not JSON parse, F3 admission, complete record, device or integrated CPU/RSS qualification.

The light object and scanner remain inactive. Root-wide structural ordering, global identity and typed-edge closure, F3 admission, F4 selected-pin normalization/product, runtime light registry, V3 transport and whole-scene performance remain open.
