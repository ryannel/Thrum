# V1 scene on the iPhone 13 simulator

4 November 2026. Selected synthetic diagnostic. Source is the checked-in `v1-scene` and `v1-scene-ios` workspace packages with the locked Rust 1.99.1 dependency set. Build with `RUSTC_WRAPPER= bash examples/v1-scene-ios/ios/build-simulator.sh`; install and launch `target/v1-scene-ios-sim/ThrumV1.app` with Xcode 27.2 `simctl`. Target: iOS 27.2 iPhone 13 simulator on an Apple M3 Max Mac; adapter reports **Apple iOS simulator GPU**, surface `Bgra8Unorm` at 1170×2289. The same 10,000-entity/1,500-mover fixed-step world and synthetic clustered-forward/two-cascade scene used on Mac and Chrome runs here.

The large black bands and diagnostic geometry are not V1 visual acceptance. This simulator measurement does not establish physical iPhone CPU, GPU, thermal, power or sustained frame budgets. Background/resume, surface/device loss, touch input and cooked hot reload were not exercised. The earlier black-screen launch was traced to an unattached Winit window; the separate UIKit scene bridge fixed it. The first device request also failed because wgpu's default 16 interstage variables exceeded the simulator's 15; the final run uses the selected downlevel request.
