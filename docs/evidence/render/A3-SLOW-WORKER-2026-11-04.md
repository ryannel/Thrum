# A3 slow-worker visual liveness

4 November 2026. Apple M3 Max/Metal, Rust 1.99.1, 10k-entity V1 synthetic scene. This slice keeps the last **completed** render target eligible for a surface-only presentation while native extraction is busy. The host pins that target's frame slot until its GPU submission completes; it does not submit scene passes or instance uploads for a reused view. A new cooked visual generation invalidates the reuse source. Each sample reports its source tick, visual age and `reused_visual`, and the window reports the reuse count. Report ordering uses GPU submission identity because successive reused views share one source tick. W1 ticks continue even when the worker cannot accept another optional view.

An opt-in Metal test blocks the worker after the first extraction, commits 600 further world ticks and presents the first completed target on each zero-update surface callback. It asserts 600 counted shed fresh views, 600 reused surface submissions, zero instance uploads and zero timing faults. With Metal timestamp queries requested, each reused sample reports **zero scene-pass durations and one measured presentation pass**. After release, the over-horizon worker result is discarded and a fresh view from tick 602 is submitted at visual age zero. A unit regression proves a completed reused report can drain while a newer submission with the same source tick remains pending. Native strict checks and a Wasm library check pass.

This proves the fallback's scheduling, slot lifetime and timestamp classification with a synthetic output view. It does not measure visible-window cadence, pixel identity across a platform surface, GPU pressure, full-process allocations, whole-frame CPU or retained peak. The source target must become free before reuse; under a slow GPU, the host may skip a presentation rather than block a world tick. The synthetic scene has no temporal pass; future temporal consumers must use `reused_visual` to invalidate their history. The combined F1 graph and owned GPU packet remain open.
