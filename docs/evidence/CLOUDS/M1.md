# CLOUDS M1 evidence

The builder implemented the renderer-free `thrum-cloud-model` crate on this M3
Max (macOS, the `mac-metal` target; no GPU is needed for its CPU tests). All
inputs are synthetic test data rather than game types, presets or looks.

- M1.1: `state` runs 5,184,000 ticks at each of 1× and 60×, changes wind mid-run,
  and compares integrated travel with an independent extended-precision TwoSum
  sum. It checks replay bytes, response rate, display travel, and rejected ticks.
- M1.2–5: `field`, `drift`, `continuity` and `births` check monotonic coverage over
  400 columns at both type ends and the middle, bit-exact drift over a day,
  temporal convergence over a day and spatial overlaps, and 900 sites over six
  hours for seeds 1, 7 and 42. Continuity compares geometric depth (`top-base`)
  through clear columns; their all-zero sentinel has no geometric top.
- M1.6–7,12,15: `density`, `placed`, `directed` and `placed_sun_path` integrate
  public density independently, include an asymmetric overhang and hollow, check
  blends and additive columns, and reject overlaps/capacity without changing
  shapes. Equal footprints with opposite interior sheets give different slant
  depths. That last fixture disables erosion to isolate voxel geometry.
- M1.8,14: [oracle invocation](M1-optical-reference.py), [printed values](M1-optical-reference.txt),
  `optics` tests and [measured phase bounds](M1-phase.md). Sphere quadrature and
  the closed-form moments are independent of phase/table construction.
- M1.9: `conformance` checks both weather columns and full/coarse slant paths,
  detects a 0.75 injected error and rejects nonfinite providers.
- M1.10–11: the crate has no dependencies. [Provenance](PROVENANCE.md) records
  that no Broadsides file was copied or translated.

The complete CPU suite (18 tests) and Clippy passed on source checkpoint
`64d5fe6b`. The field test also covers extreme finite coordinates, with defined
wrapping of integer neighbours rather than debug-build overflow. Birth-count
variance/mean was 1.026683, 1.012132 and 1.087063 for the three seeds; the largest
generation-harmonic power/mean was 2.046083, below 4.6. The reference invocation
used CPython 3.14.5 and NumPy 2.3.5; its temporary environment/cache were removed.

The final target-verification revision, verifier output and merged revision are
recorded in [the module log](../../plans/CLOUDS/LOG.md). The build script retains
the full check stdout/stderr in its shared Git check store. M1.13's live verifier
tests both native matrices and all four registered Chrome sets; it reads no
temporary evidence as an input. An initial invocation reached the second native
matrix before its wrapper's 600-second timeout; the final invocation uses a
3,600-second allowance. The timeout was not an image mismatch.

This CPU milestone claims no cloud visuals or GPU performance; later milestones
own those proofs. No retained image, existing test or numerical bound changed.
