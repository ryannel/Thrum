# SEA provenance

SEA M1 lifts nothing from Broadsides. No file is copied or translated from it,
and no Broadsides asset is used. No owner licence is inferred.

The CPU model and its tests were written in this repository from the SEA design
and published mathematics: [Tessendorf's ocean-water notes](https://jtessen.people.clemson.edu/reports/papers_files/waterslides2001.pdf)
for Fourier/Gerstner displacement and deep-water dispersion, and the
[USACE BOUSS-2D JONSWAP appendix](https://coastalhydraulicslaboratoryfact.tpub.com/BOUSS-2D/BOUSS-2D0082.htm)
for the fetch-limited spectral form. The full-development limit uses
Pierson–Moskowitz alpha 0.0081, gamma 1 and peak frequency 0.877 g/U.

The inverse radix-two transform is an original small scalar reference, not a
performance implementation. No third-party dependency was added. Its independent
test sums the Fourier series directly, grouped by common z frequency without
butterflies. The extended-precision fixture is generated by the retained Python
Decimal script using Taylor trigonometry and exact binary64 input conversion.

SEA M2 also copies or translates nothing from Broadsides. Its WGSL Fourier transform,
integer loop phase, differential channels, moment reductions and long-wave evaluator
were written here against the CPU model. No third-party source or asset was added.
