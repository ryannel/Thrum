# I1 charged immutable payload bytes

1 November 2026. `PublicationBytes::required_charge` exposes the checked logical charge for a given length so a caller can plan a whole-tick reservation without relying on private layout. `try_copy_from_slice` reserves payload length plus the shared owner and reference-count header before making a retained copy. `try_copy_from_reservation` transfers that charge from an existing reservation, without double-reserving the pool. An oversized request leaves the pool and reservation unchanged. The retained copy is independent of later source mutation. Clones share the same bytes and one charge; the final clone's drop releases that charge. An empty payload still charges its owner. Checked arithmetic rejects an unrepresentable charge.

`RUSTC_WRAPPER= ./dev check` runs the capacity, source-isolation, sharing, reservation-transfer and last-owner unit tests alongside the existing concurrent pool tests and I1 authority/replica tests. Source identity: `crates/thrum-core/src/publication_pool.rs` SHA-256 `1a70b02c816e123117745dde60149e688d43718b6df9495a804e70731a64dded`. A nonempty byte product has two allocations, one for the exact-length boxed bytes and one for the shared owner. A clone increments the reference count without copying bytes; equality compares content and is linear in payload length. These are representation and code-path facts, not a measured throughput or resident-memory result.

The budget counts logical retained payload and owner bytes; it does not count caller-owned source storage, allocator metadata, or other fields of a game action or entity. A transport decoder must bound its source separately. This type is not yet used by the I1 game's action, authoritative world, input history, baseline, or replica. The [whole publication-memory gate](../../design/I1-HEADLESS.md#publication-memory-admission-gate) remains open.
