# I1 precommit snapshot peak bound

1 November 2026. `World::conservative_charged_publication_peak(max_edits, max_spawns)` computes a snapshot page/root reservation before a proposed edit batch. It reads the current slot count, dirty-page count and publication mode, then uses the declared maximum touched slots and spawns. The maximum root page count is `ceil((current slots + max spawns) / 32)`; the maximum dirty-page count is the smaller of that page count and `current dirty pages + max(max edits, max spawns)`. Each possible dirty page is priced as a full 32-slot page. The root, new page owners, possible Vec-to-Box staging overlap and initial empty-root overlap are included with checked arithmetic. This calculation is O(1) in world size.

`RUSTC_WRAPPER= ./dev check` includes a 65-spawn/65-despawn test. The test calculates and reserves the bound **before** applying 130 prepared edits, verifies that a pool one byte below that bound rejects admission while the world is unchanged, and then publishes three charged pages even though no object survives. The post-edit exact snapshot reservation is at most the precommit bound. A second test starts with an already dirty partial page, reserves before two spawns cross the 32-slot boundary, then verifies the bound and both copied pages. Another assertion checks that an idle charged world returns zero. Source identity: `crates/thrum-core/src/world.rs` SHA-256 `7896447ca514a128b6bb418bc281ad1da3913fdad5082c73e66a66254e184477`.

The bound is for snapshot page/root owners only. It does not validate that a game respects `max_edits` or `max_spawns`, charge game-owned heap data, cover mutable world indexes, groups, results, events, baselines or replica storage, or make the current `GameRules::commit` path precommit-admitted. The measured charged-page path remains in [CHARGED-PAGES](CHARGED-PAGES.md). The [whole byte gate](../../design/I1-HEADLESS.md#publication-memory-admission-gate) remains open.
