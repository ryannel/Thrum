The most relevant **protected-path** timing records are the paired no-spawn fixed/structural submit-to-callback-to-replica-to-ack runs at 4,096 and 16,384 objects, and the maximum two-peer structural callback-to-ack batch at those sizes. The [structural cost record](STRUCTURAL-CREDITS.md) reports fixed/structural one-change p50 ranges of 0.875–1.042 µs at 4,096 and 1.792–1.958 µs at 16,384, with overlap at the larger size; the 16-input/32-spawn batch p50 ranges were 7.250–8.041 µs and 8.542–8.625 µs respectively. Those runs belong to earlier code checkpoints and were not repeated against the complete current source. They are release-mode diagnostics on one local Apple Silicon environment, not portable latency bounds. The [scratch comparison](RULE-SCRATCH.md) shows a four-byte retained owner difference and a small, noise-limited callback cost. The original [scale/churn fixture](QUALIFICATION.md) remains useful for work counts but predates protected storage and must not be treated as its current integrated performance result.

The local machine reported macOS 26.6.2 and Rust 1.99.1. Hardware model and counters were unavailable to this task, so **no named Mac performance configuration is qualified**. Windows, browser runtime, iPhone and Android behavior/performance remain unrun. The Wasm compile is a portability check only. There are no image, audio, gameplay feel or human quality results for this headless slice.

The [central work list](../../BUILD-PLAN.md) therefore keeps representative process-memory measurements and phone shells open. Its published-copy box is checked only for the selected fixed-slot and finite-growth hosts. I1 as a whole remains partial in the [maturity ledger](../../design/maturity.json). The hard whole-process cap has been retired in favor of measured low memory use; the optional strict pool profile remains scoped. Xcode simulator launch exposed an iOS 27 scene/presentation gap in the pinned mobile backend. The Android APK assembles but has no runtime proof. A bounded remote queue/transport owner is still open. These need separate qualification before broader platform or multiplayer claims close.
