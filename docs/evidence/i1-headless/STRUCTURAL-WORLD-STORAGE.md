# Bounded structural world-owner slice

1 November 2026. This is a **world-only implementation proof**, not a qualified structural authority or host. It implements the storage and same-barrier identity portion of the [selected design](STRUCTURAL-GROWTH-DESIGN.md). The authority still lacks per-action spawn classification, future-credit upgrades and an absolute-horizon due preflight; the protected host remains fixed-slot.

`World::activate_structural_journal` requires an already charged, clean world and a matching pool. It reserves the proposed slot, dirty, free, live-ID and touched-ID/journal allocations **plus old/new overlap** before replacing any owner. The live ID and journal hashbrown tables reserve twice their logical maximum and assert stable allocation after insert/remove churn. Physical slots and live objects have separate caps. Generation-exhausted slots retire instead of rejoining the free list. The activation function stays crate-private until the authority admission path can invoke it safely.

The journal keys changes by stable ID, so `Despawn(A)` followed by `Spawn(B)` in the same slot emits two sorted lifecycle records. A new spawn canceled before publication leaves one neutral journal entry; a later spawn of the same unpublished ID reuses that entry. Mixed neutral/live publication retains a vector whose requested capacity can exceed its length; the charged group wrapper now charges `changes.capacity()` instead of `changes.len()`. Existing fixed-slot world behavior remains a separate fast path.

Local proof at this slice's checkpoint: `RUSTC_WRAPPER= ./dev check` passed (68 core, 6 clock and 55 game tests). New focused cases cover activation refusal, old-reader state, same-slot generation change and sorted identities, cancellation/reuse without duplicate touches, 1,000 identity churn cycles with stable map allocations, mixed neutral/live output capacity, generation retirement, physical cap refusal and exact final pool release. A later structural-host checkpoint tightened the activation case to leave exactly one byte less than its requested old/new overlap peak; it still refuses before replacing any owner. The review agent found no remaining issue after the mixed-capacity charge correction. Authority-level accepted-input liveness, replica and host integration are covered separately in the [structural credit proof](STRUCTURAL-CREDITS.md).

Local Apple Silicon release-mode **world-only** cost fixture: `cargo test -p thrum-core --lib --release compare_fixed_and_structural_one_change_publication_cost -- --ignored --nocapture`. The fixture publishes one changed object in a 4,096-object world for 6,000 iterations per mode, discarding the first 1,000. Four serial runs reported fixed-slot 575/498/490/456 ns per iteration and structural 623/543/534/494 ns. The structural path was about 8–10% slower in this ordered fixture. This is a diagnostic comparison of world mutation, reservation and publication; it excludes authority, rule, required replica and host callback work, and its order and machine noise limit the inference. The fixed-slot specialization remains active for no-spawn games. Complete-path structural and no-spawn comparisons are required before a performance qualification.
