# I1 closed record authority admission

1 November 2026. `Authority::try_new_closed_snapshot_charged` accepts only a sealed engine-owned `ClosedPublicationValue`. It checks the entity type's fixed shape even for an empty world, then checks every initial state against its selected `PublicationPool` and `ClosedValueLimits` before reserving or publishing tick zero. The limits bound fixed inline bytes, payload handle slots and bytes in each payload owner. The qualified authority stores a function pointer for payload checks on each prepared spawn or replacement before applying any edit. This reuses the same `GameRules::decide` and `prepare` callbacks as standalone and match authorities. The older generic charged constructor remains a prototype path and does not claim this value gate.

The `i1_game` fixture now runs its fixed-counter plus charged-payload authority through the qualified entry path and replica. A second fixture rejects an initial foreign payload with `WrongPool` and an oversized initial payload with `ValueProfile`. It then executes two-edit batches whose first replacement is valid and second spawn carries either a foreign or oversized payload. The authority reports `TerminalGameContract`, retains tick zero, and refuses replay; live-world assertions show neither edit applied. A separate empty-world fixture rejects an oversized record type before publication. A unit test checks all three size limits and foreign-pool rejection. `RUSTC_WRAPPER= ./dev check` runs these fixtures and the repository gates.

Type shape validation is constant time at construction. Initial payload validation scans the contiguous slot array once, with work proportional to slot high-water plus live states times the record's payload slots. Each prepared action checks only its new states and payload slots; a no-input tick performs no record scan. Each present payload receives a pointer provenance check and byte-length comparison. The check borrows values, uses no validation vector, and makes no payload copy. These are code-path bounds, not a measured latency result. The gate does not bound action/event/rejection values, other authority allocations, group output, replica state, baseline delivery, or private game scratch, so the parent publication-memory task stays open.
