## Source equations and numeric endpoints

Let B(q) be the fixed decoded reference, with 0<=B<=C=0.125 m^-1. The source is

    sigma(q,s)=max(B(q)-C*(1-S((s-b(q))/55))-C*S((s-d(q))/40),0)

where S is the monotone bounded quintic smootherstep. The spatial birth onset b is in [5,31] s. The death onset d is in [130,200] s because its bounded material-space macro field uses coefficients summing to 0.5 around a 0.5 mean. Actual grid samples have b in [5,31], d in [130.0094744,199.9903722].

At s=0 the birth threshold is exactly C and the death threshold zero, so every value is zero because B<=C. At s=240 all birth is complete and the death threshold is exactly C, so every value is again zero. There is no early endpoint return hiding a nonzero formula. Both subtracted thresholds are nonnegative, so the source cannot create values outside the base support or exceed the fixed optical maximum. These are optical authoring operations, not condensate conservation or a fluid solver.

The stable symmetric float64 quintic evaluation avoids near-one cancellation before float32 conversion. Independently sampled 100001 inputs from -0.1 through1.1: exact extrema 0 and1, monotone, exact endpoint plateaus. Evaluated actual fields at 0,20,50,60,67.5,90,140,165,185,200,215,240: all nonnegative, maximum<=0.125, eight-voxel collars exactly zero, both terminal fields exactly zero.

The source has a conservative support invariant: every frame's positive voxels are a subset of the fixed base's positive support. Thus its static base bounds are a valid voxel ROI for every source age. Any cropped trilinear consumer still needs its ordinary zero/filter halo; this source audit does not certify a separate ROI implementation.
