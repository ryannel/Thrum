## Verified exporter traps and units

The initial64³ VDB pilot cannot qualify the carrier. Actual frame65 has density and velocity active bbox `((36,31,14),(44,38,21))`, only75 active voxels each. The standard smoke VDB writer clips sparse velocity by the density grid; resumable cache does not fix it, and an ordinary clipping-threshold setting cannot remove that structural mask. Default VDB fields were saved as half floats. Use **UNI**, not this VDB export, for the complete independent carrier/master. UNI stores the full grid as float32 without a density mask.

Pinned primary source:

- [fluid.cc](https://raw.githubusercontent.com/blender/blender/e13b728c6880/source/blender/blenkernel/intern/fluid.cc): `DT_DEFAULT=.1`; internal frame duration `.1*(25/fps)*time_scale`; input world-to-grid velocity conversion.
- [fluid_script.h](https://raw.githubusercontent.com/blender/blender/e13b728c6880/intern/mantaflow/intern/strings/fluid_script.h): MAC velocity allocation, final cache inclusion, raw component copy and VDB export.
- [smoke_script.h](https://raw.githubusercontent.com/blender/blender/e13b728c6880/intern/mantaflow/intern/strings/smoke_script.h): density/velocity cache export with density clip grid; no microphysical cloud model.
- [iovdb.cpp](https://raw.githubusercontent.com/blender/blender/e13b728c6880/extern/mantaflow/preprocessed/fileio/iovdb.cpp): raw value export, density-mask clipping, half precision and origin-only linear voxel transform.
- [iogrids.cpp](https://raw.githubusercontent.com/blender/blender/e13b728c6880/extern/mantaflow/preprocessed/fileio/iogrids.cpp): gzip MNT3,288-byte header then X-fastest float32 scalar/vector grid. The new reader is independently written from that format description.

For source step `ds`, target cell width `dx_m`, raw MAC velocity `u`, exported physical carrier is `u*dx_m*(.1*25/fps*time_scale)/ds`. At128³/512m, fps8, time_scale1, ds1.875 this is **u*(2/3)m/source-second**. It is not raw metres/second. A32Blender-unit domain maps to512m; frame1→0s, frame129→240s. Recenter each MAC component from its lower face using its positive-axis neighbour, then transform `(x,y,z)→(x,z,-y)`. Preserve fixed scalar sampling and remove no bulk drift unless both scalar coordinates and velocity are reframed together. The pilot VDB transform has index origin0, spacing.5 for64³; it omits the object's physical translation, so recover cell centers from the fixed domain bounds and recipe, never a changing active bbox. A controlled passive-advection bake should independently confirm the unit/centering deduction; density landmarks alone cannot because emission/dissipation changes density.

A fixed nonzero optical remap is legitimate authored content, but must remain identical across all frames. No global age fade, per-frame normalization, density-based velocity masking, carrier clipping, inserted empty endpoint or temporal reference synthesized from interpolation is permitted. Source/frame/range/collar/byte/V/L failures are reported unchanged.

## Challenge to the chosen gas recipe

A hot buoyant inflow and strong vorticity naturally produce a rising plume or mushroom. That can fail the cumulus-like target even with convincing fluid motion. A cold/weakly buoyant finite inflow and modest vorticity is a useful alternative pilot; those are authoring assumptions, not researched universal settings. Linear dissolve can sever thin necks as low-density cells vanish; logarithmic dissolve is closer to a uniform multiplicative fade and is a poor sole breakup mechanism. The current pilot has vanished by frame75; stretching the playbar to240s does not create240s of interesting structural evolution. Inspect actual quarter frames and1x/16x/64x clips; retain rejection when morphology/cadence fails. Tight runtime `V<=2m/s,L<=.02/s` may reject this source. Do not independently slow only the carrier or smooth it until the fit is hidden.
