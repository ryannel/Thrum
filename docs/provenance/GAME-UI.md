# GAME-UI asset provenance

The interface scene's outline face is Roboto Regular by Google and Christian Robertson, distributed under Apache 2.0.
The binary is unchanged from the pinned upstream commit. Its license is retained alongside the font.
[Roboto-Regular.ttf and license](https://github.com/googlefonts/roboto-2/tree/38062f4b4a0be4346d07a928408da21602545e9e)

The interface scene's pixel font is original artwork for Thrum. The PNG and cell description are retained together.

## Crowd status display

The Crowd status display uses the same Roboto Regular face qualified for GAME-UI WP2.
`examples/crowd-2d-status/assets/type/Roboto-Regular.ttf` is a byte-for-byte copy of the
licensed source in `tests/fixtures/game-ui/font-source/type/`, with its Apache 2.0 text beside
it. The Crowd package owns its single 16-point cooker recipe and the status panel geometry.
The replay sprites and rules come from the existing Crowd example packages.
