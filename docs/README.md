# Documentation

[The plans folder](plans/STATUS.md) holds the status page, [the brief](plans/BRIEF.md), [the module list](plans/ARCHITECTURE.md) and each module's design, plan, log and done-when file. [Design](design/README.md) indexes the
whole engine, contracts and selected initial mechanisms. [Repository layout](REPOSITORY.md) and
[asset lifecycle](ASSET-LIFECYCLE.md) apply to work here.

[Evidence](evidence/README.md) contains dated supporting reports, which can be superseded by the
current specifications. [Import provenance](provenance/IMPORT.md) explains source history and hashes.
