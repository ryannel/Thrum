# Tests behind a Cargo feature. `./dev check` builds and lints the tests of each package named here
# with these features on; `./dev long-tests` runs its tests that are not ignored, in the debug build,
# with the features on and a GPU required (an ignored test there is a measurement a cost script runs).
# With no binary named, a line covers every test binary of the package, the library's own tests
# included, so a new gated file runs with no edit here. The binary `lib` names the library's own
# tests. `./dev check-docs` fails when a test target's `required-features`, or a `cfg` that gates test
# code (in a test file, or a test module, `#[test]` item or `cfg(test, ...)` in any source file), names
# a feature no line covers for that package, whole or by the binary the code builds into. A feature
# the workspace's own build turns on needs no line.
#
# <package> features=<feature>[,<feature>...] [<test binary> ...]
